# Lektion 04: Passiv mit Modalverben und Alternativen

**Level:** B1 | **Target time:** 30 minutes, repeat over 3 sessions | **Status:** not started

---

## Goal

Use the passive with modal verbs in all tenses, and replace the passive with `man`, `sich lassen`, and adjective forms.

## Why this matters

Modal + passive is the standard way German expresses obligation, permission, and possibility in formal contexts: "must be done", "can be solved", "should be submitted". You meet it in every form, contract, and instruction. The alternatives matter too, because good German varies its structures.

---

## Material

### Modal + passive: the core pattern

`Modalverb` + **Partizip II** + **werden**

The modal carries the tense; `werden` stays as the infinitive at the end.

| Tense | Structure | Example |
|---|---|---|
| Präsens | muss + P2 + werden | Das Formular **muss** ausgefüllt **werden**. |
| Präteritum | musste + P2 + werden | Das Formular **musste** ausgefüllt **werden**. |
| Perfekt | hat + P2 + werden + müssen | Das Formular **hat** ausgefüllt **werden müssen**. |

**Note the Perfekt:** the modal becomes an infinitive at the very end (`müssen`), after `werden`. This creates a "double infinitive" at the end. It looks strange but is correct.

`Das Formular hat ausgefüllt werden müssen.` (The form had to be filled out.)

### The modals in the passive

| Modal | Meaning in passive | Example |
|---|---|---|
| müssen | must be | Das muss gemacht werden. |
| können | can be | Das kann gemacht werden. |
| sollen | should be | Das soll gemacht werden. |
| dürfen | may be, is allowed | Das darf nicht gemacht werden. |
| wollen | wants to be | Das will gemacht werden. |
| mögen | would like to be | Das möchte gemacht werden. |

### Present tense: full examples

| German | English |
|---|---|
| Die Rechnung muss bezahlt werden. | The bill must be paid. |
| Das Problem kann gelöst werden. | The problem can be solved. |
| Der Antrag soll gestellt werden. | The application should be submitted. |
| Hier darf nicht geraucht werden. | Smoking is not allowed here. |
| Das Auto muss repariert werden. | The car must be repaired. |
| Die Tür kann geöffnet werden. | The door can be opened. |

### Past tense (Präteritum)

`Der Antrag **musste** früher gestellt werden.` (The application had to be submitted earlier.)
`Das Problem **konnte** gelöst werden.` (The problem could be solved.)
`Die Rechnung **sollte** gestern bezahlt werden.` (The bill should have been paid yesterday.)

### Perfekt with modal + passive

`Die Rechnung **hat** bezahlt werden **müssen**.` (The bill had to be paid.)
`Das Problem **hat** gelöst werden **können**.` (The problem could be solved.)

This is rare in speech but appears in formal writing and exams.

### Negation

`Das **darf nicht** gemacht werden.` (That must not be done.)
`Das **kann nicht** gemacht werden.` (That cannot be done.)
`Das **muss nicht** gemacht werden.` (That does not have to be done.)

**Watch the difference:**
- `darf nicht` = must not (prohibited)
- `muss nicht` = does not have to (not necessary)

### Alternative 1: man

`man` avoids the passive and is common in everyday German.

| Passive | man-version |
|---|---|
| Das Formular muss ausgefüllt werden. | Man muss das Formular ausfüllen. |
| Hier wird nicht geraucht. | Hier raucht man nicht. |
| Die Rechnung wird bezahlt. | Man bezahlt die Rechnung. |

Both are correct. The passive is more formal.

### Alternative 2: sich lassen

`sich lassen + Infinitiv` = "can be done". A neat replacement for `können` + passive.

`Das Problem **lässt sich** lösen.` = `Das Problem kann gelöst werden.` (The problem can be solved.)
`Das **lässt sich** machen.` = `Das kann gemacht werden.` (That can be done.)
`Das **lässt sich** nicht ändern.` = `Das kann nicht geändert werden.` (That cannot be changed.)

**Conjugation of lassen:** ich lasse, du lässt, er lässt, wir lassen, ihr lasst, sie lassen.
Präteritum: ich ließ, du ließest, er ließ, wir ließen.

### Alternative 3: sein + zu + Infinitiv

`sein + zu + Infinitiv` = "is to be done" / "must be done".

`Das Formular **ist** auszufüllen.` (The form is to be filled out.)
`Die Rechnung **ist** bis Freitag zu bezahlen.` (The bill is to be paid by Friday.)

This is formal and common in written German. It implies obligation or possibility.

### Alternative 4: -bar adjectives

Many verbs form an adjective with **-bar** meaning "can be done".

| Verb | Adjective | Meaning |
|---|---|---|
| machen | machbar | doable |
| lösen | lösbar | solvable |
| bezahlen | bezahlbar | payable, affordable |
| verstehen | verständlich* | understandable |
| essen | essbar | edible |
| trinken | trinkbar | drinkable |
| reparieren | reparierbar | repairable |
| ändern | veränderbar | changeable |

`Das ist **machbar**.` (That is doable.)
`Das Problem ist **lösbar**.` (The problem is solvable.)

*Note: `verständlich` comes from `verstehen` but is not a simple -bar form; it is a related adjective.

### Choosing the right structure

| Situation | Best choice |
|---|---|
| Formal writing, rules | Passive |
| Everyday speech | man |
| Emphasising possibility | sich lassen |
| Formal obligation | sein + zu + Infinitiv |
| Describing a thing's quality | -bar adjective |

### Worked comparison

Same meaning, five ways:

1. **Passive:** Das Problem kann gelöst werden.
2. **man:** Man kann das Problem lösen.
3. **sich lassen:** Das Problem lässt sich lösen.
4. **sein + zu:** Das Problem ist zu lösen.
5. **-bar:** Das Problem ist lösbar.

All five are correct. Varying them makes your German sound natural and mature.

## Exercises

**1. Modal + passive (Präsens).**

a) Man muss die Rechnung bezahlen. → Die Rechnung ______ .
b) Man kann das Problem lösen. → Das Problem ______ .
c) Man soll den Antrag stellen. → Der Antrag ______ .
d) Man darf hier nicht rauchen. → Hier ______ .

**2. Modal + passive (Präteritum).**

a) Man musste die Rechnung bezahlen. → Die Rechnung ______ .
b) Man konnte das Problem lösen. → Das Problem ______ .

**3. darf nicht or muss nicht?**

a) Hier ______ geraucht werden. (prohibited)
b) Das ______ gemacht werden. (not necessary)
c) Das ______ gemacht werden. (must not)
d) Du ______ kommen. (not necessary)

**4. Rewrite with sich lassen.**

a) Das Problem kann gelöst werden. → Das Problem ______ .
b) Das kann gemacht werden. → Das ______ .
c) Das kann nicht geändert werden. → Das ______ .

**5. Rewrite with sein + zu + Infinitiv.**

a) Das Formular muss ausgefüllt werden. → Das Formular ______ .
b) Die Rechnung muss bis Freitag bezahlt werden. → Die Rechnung ______ .

**6. Form the -bar adjective.**

a) machen → ______
b) lösen → ______
c) essen → ______
d) reparieren → ______

**7. Translate into German.**

a) The bill must be paid.
b) The problem can be solved.
c) Smoking is not allowed here.
d) The form has to be filled out.
e) That cannot be changed.

**8. Fix the mistake.**

a) Das Formular muss ausgefüllt.
b) Das Problem lässt sich lösen werden.
c) Die Rechnung hat bezahlt werden gemusst.
d) Das darf nicht gemacht werden. (is this correct?)

### Answer key

**1.**
a) Die Rechnung muss bezahlt werden.
b) Das Problem kann gelöst werden.
c) Der Antrag soll gestellt werden.
d) Hier darf nicht geraucht werden.

**2.**
a) Die Rechnung musste bezahlt werden.
b) Das Problem konnte gelöst werden.

**3.**
a) darf nicht
b) muss nicht
c) darf nicht
d) musst nicht

**4.**
a) Das Problem lässt sich lösen.
b) Das lässt sich machen.
c) Das lässt sich nicht ändern.

**5.**
a) Das Formular ist auszufüllen.
b) Die Rechnung ist bis Freitag zu bezahlen.

**6.**
a) machbar
b) lösbar
c) essbar
d) reparierbar

**7.**
a) Die Rechnung muss bezahlt werden.
b) Das Problem kann gelöst werden.
c) Hier darf nicht geraucht werden.
d) Das Formular muss ausgefüllt werden.
e) Das kann nicht geändert werden.

**8.**
a) Das Formular muss ausgefüllt **werden**. (modal passive needs werden)
b) Das Problem lässt sich lösen. (sich lassen takes a bare infinitive, no werden)
c) Die Rechnung hat bezahlt werden **müssen**. (Perfekt modal passive ends in the modal infinitive)
d) Correct. `darf nicht gemacht werden` is right.

## Pronunciation note

The double infinitive at the end (`werden müssen`) is stressed on the first syllable of each: "VER-den MUS-sen". Practise the rhythm; it feels unusual at first.

## Common mistakes

- Wrong: `Das Formular muss ausgefüllt`. Right: `... ausgefüllt werden`.
- Wrong: `Das lässt sich lösen werden`. Right: `Das lässt sich lösen`. (no werden after lassen)
- Wrong: confusing `darf nicht` (must not) and `muss nicht` (does not have to).
- Wrong: Perfekt modal passive ending in `gemusst`. Right: `... werden müssen`.
- Wrong: using `sein + zu` for a general statement where a -bar adjective fits better.
