# Lektion 04: Perfekt und Partizip II

**Level:** A2 | **Target time:** 30 minutes, repeat over 4 sessions | **Status:** not started

---

## Goal

Form the Partizip II correctly for regular, irregular, and mixed verbs, and handle separable and inseparable verbs in the Perfekt.

## Why this matters

The helper verb (haben/sein) is easy. The **Partizip II** is the hard part, because German has strong (irregular) verbs with unpredictable forms. This lesson gives you the patterns, so you can form most participles and recognise the rest.

---

## Material

### Regular (weak) verbs: ge- + stem + -t

| Infinitive | Partizip II | English |
|---|---|---|
| lernen | gelernt | learned |
| machen | gemacht | made, did |
| kaufen | gekauft | bought |
| spielen | gespielt | played |
| arbeiten | gearbeitet | worked |
| wohnen | gewohnt | lived |
| hören | gehört | heard |
| sagen | gesagt | said |
| fragen | gefragt | asked |
| kochen | gekocht | cooked |

**Verbs ending in -t or -d add an extra e**: `arbeiten` → `gearbeitet`, `reden` → `geredet`.

### Irregular (strong) verbs: ge- + changed stem + -en

| Infinitive | Partizip II | English |
|---|---|---|
| gehen | gegangen | gone |
| kommen | gekommen | come |
| sehen | gesehen | seen |
| lesen | gelesen | read |
| essen | gegessen | eaten |
| trinken | getrunken | drunk |
| sprechen | gesprochen | spoken |
| schreiben | geschrieben | written |
| fahren | gefahren | driven |
| fliegen | geflogen | flown |
| nehmen | genommen | taken |
| geben | gegeben | given |
| finden | gefunden | found |
| singen | gesungen | sung |
| schlafen | geschlafen | slept |
| helfen | geholfen | helped |
| treffen | getroffen | met |
| bleiben | geblieben | stayed |
| sein | gewesen | been |

Notice: strong verbs end in **-en**, not -t. The vowel often changes.

### Mixed verbs

Mixed verbs change the vowel **and** take -t. There are only about 10 of them.

| Infinitive | Partizip II | English |
|---|---|---|
| bringen | gebracht | brought |
| denken | gedacht | thought |
| kennen | gekannt | known |
| nennen | genannt | named |
| rennen | gerannt | run |
| senden | gesendet | sent |
| wenden | gewandt | turned |
| wissen | gewusst | known |
| brennen | gebrannt | burned |
| verbringen | verbracht | spent (time) |

### Separable verbs: prefix + ge- + stem

For separable verbs, the `ge-` goes **between** the prefix and the stem.

| Infinitive | Partizip II | English |
|---|---|---|
| aufstehen | aufgestanden | got up |
| einkaufen | eingekauft | shopped |
| anrufen | angerufen | called |
| aufmachen | aufgemacht | opened |
| zumachen | zugemacht | closed |
| mitkommen | mitgekommen | came along |
| einladen | eingeladen | invited |
| fernsehen | ferngesehen | watched TV |
| anfangen | angefangen | started |
| aufräumen | aufgeräumt | tidied up |

`auf|gestanden`, `ein|gekauft`, `an|gerufen`. The ge- sits inside the word.

### Inseparable verbs: NO ge-

Verbs with inseparable prefixes (**be-, ge-, er-, ver-, zer-, ent-, emp-, miss-**) take **no** ge-.

| Infinitive | Partizip II | English |
|---|---|---|
| besuchen | besucht | visited |
| bekommen | bekommen | received |
| verstehen | verstanden | understood |
| verkaufen | verkauft | sold |
| erzählen | erzählt | told |
| erklären | erklärt | explained |
| vergessen | vergessen | forgotten |
| verlieren | verloren | lost |
| beginnen | begonnen | begun |
| gefallen | gefallen | pleased |

`Ich habe ihn besucht.` ✅
`Ich habe ihn gebesucht.` ❌

### Verbs ending in -ieren: NO ge-

| Infinitive | Partizip II | English |
|---|---|---|
| studieren | studiert | studied |
| telefonieren | telefoniert | phoned |
| trainieren | trainiert | trained |
| informieren | informiert | informed |
| passieren | passiert | happened |
| funktionieren | funktioniert | worked (functioned) |

`Ich habe studiert.` ✅ (not `gestudiert`)

## Pronunciation note

In `gegessen`, the two g sounds differ: the first is a soft g, the second is part of "essen". Practise slowly: ge-GES-sen.

## Common mistakes

- Wrong: `gebesucht`, `gestudiert`. Right: `besucht`, `studiert`. Inseparable and -ieren verbs take no ge-.
- Wrong: `geeinkauft`. Right: `eingekauft`. The ge- goes inside the separable verb.
- Wrong: treating all verbs as regular: `gegeht`. Right: `gegangen`.
- Wrong: forgetting strong verbs end in -en: `gesprecht`. Right: `gesprochen`.
