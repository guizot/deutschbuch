# Lektion 02: Verben mit Dativ und Akkusativ

**Level:** A2 | **Target time:** 30 minutes, repeat over 3 sessions | **Status:** not started

---

## Goal

Handle verbs that take **two** objects, put them in the correct order, and use the right pronoun forms.

## Why this matters

This is where the dative earns its keep. Sentences like `Ich gebe dem Mann das Buch` have both cases in one sentence. Getting the order right (person before thing) is a core German skill, and it appears in every exam.

---

## Material

### Verbs with two objects

These verbs take a **dative person** and an **accusative thing**.

| Verb | English | Example |
|---|---|---|
| geben | to give | Ich gebe **dem Kind** (D) **den Ball** (A). |
| bringen | to bring | Er bringt **mir** (D) **das Buch** (A). |
| kaufen | to buy (for someone) | Ich kaufe **dir** (D) **ein Geschenk** (A). |
| schenken | to give as a gift | Sie schenkt **ihm** (D) **eine Uhr** (A). |
| zeigen | to show | Zeig **mir** (D) **den Weg** (A). |
| schicken | to send | Ich schicke **ihr** (D) **eine E-Mail** (A). |
| erklären | to explain | Er erklärt **uns** (D) **die Regel** (A). |
| empfehlen | to recommend | Ich empfehle **Ihnen** (D) **das Restaurant** (A). |
| sagen | to say (to someone) | Ich sage **dir** (D) **die Wahrheit** (A). |
| leihen | to lend | Leihst du **mir** (D) **dein Auto** (A)? |
| vorstellen | to introduce | Ich stelle **Ihnen** (D) **meinen Kollegen** (A) vor. |
| wünschen | to wish | Ich wünsche **dir** (D) **viel Glück** (A). |

### The golden rule: person before thing

When both objects are nouns, the order is **dative (person) first, then accusative (thing)**.

`Ich gebe **dem Mann** (D) **das Buch** (A).` ✅
`Ich gebe **das Buch** (A) **dem Mann** (D).` — unusual, only for emphasis

If one object is a pronoun, the **pronoun comes first**.

`Ich gebe **es** (A pronoun) **dem Mann** (D).` — the pronoun `es` moves before the dative noun.
`Ich gebe **ihm** (D pronoun) **das Buch** (A).` — both pronoun? dative pronoun first.

**Rule of thumb:** pronoun before noun. When both are nouns, dative before accusative.

| Situation | Order | Example |
|---|---|---|
| Both nouns | Dativ, then Akkusativ | Ich gebe dem Mann das Buch. |
| Both pronouns | Dativ, then Akkusativ | Ich gebe ihm es. (rare) |
| Accusative pronoun + dative noun | Accusative pronoun first | Ich gebe es dem Mann. |
| Dative pronoun + accusative noun | Dative pronoun first | Ich gebe ihm das Buch. |

At A2, the safe default is: **dative person first, then accusative thing**. That covers almost everything.

### Pronoun combinations

When both objects are pronouns, they combine in a fixed order:

| Dativ | + Akkusativ | Meaning |
|---|---|---|
| mir | es | to me it |
| dir | es | to you it |
| ihm | es | to him it |
| ihr | es | to her it |
| uns | es | to us it |
| euch | es | to you (pl) it |
| ihnen | es | to them it |

For the accusative, use the accusative pronoun: `mich, dich, ihn, sie, es, uns, euch, sie`.

`Ich gebe es ihm.` (I give it to him.) — accusative pronoun `es` first, dative pronoun `ihm` second. Yes, this reverses the noun order. It is a genuine quirk: **when both are pronouns, accusative comes first**.

### Verbs with only a dative object

Some verbs take **only** the dative, no accusative.

| Verb | English | Example |
|---|---|---|
| helfen | to help | Ich helfe **dir**. |
| danken | to thank | Ich danke **Ihnen**. |
| gefallen | to please | Das gefällt **mir**. |
| gehören | to belong | Das gehört **ihm**. |
| passen | to fit | Die Schuhe passen **mir**. |
| antworten | to answer | Er antwortet **der Frau**. |
| glauben | to believe | Ich glaube **dir**. |
| folgen | to follow | Folge **mir**. |
| schmecken | to taste | Die Suppe schmeckt **mir**. |
| gratulieren | to congratulate | Wir gratulieren **dir**. |
| zuhören | to listen | Hör **mir** zu. |

### Verbs with only an accusative object

Most verbs. `kaufen`, `sehen`, `lesen`, `essen`, `trinken`, `suchen`, `finden`, `brauchen`, `nehmen`, `besuchen`, `kennen`, `mögen`, `haben`.

### How to tell them apart

There is no shortcut. When you learn a new verb, note which case it takes. A good dictionary (Leo, dict.cc) shows this as `+Dat` or `+Akk`.

A useful rule for two-object verbs: **the person is almost always the dative**, the thing is the accusative.

## Exercises

**1. Which case?** Dative or accusative? Write the correct article.

a) Ich gebe ______ Mann (der) ______ Buch (das).
b) Er zeigt ______ Frau (die) ______ Weg (der).
c) Sie schenkt ______ Kind (das) ______ Ball (der).
d) Ich schicke ______ Freund (mein) ______ E-Mail (eine).
e) Er erklärt ______ Studenten (die) ______ Regel (die).

**2. Correct word order.** Put in the right order.

a) ich / das Buch / gebe / dem Mann → ______
b) zeigt / den Weg / mir / er → ______
c) eine E-Mail / ich / schicke / ihr → ______
d) das Geschenk / wir / geben / dir → ______

**3. Pronouns.** Replace both objects with pronouns.

a) Ich gebe dem Mann das Buch. → Ich gebe ______ ______.
b) Er zeigt der Frau den Weg. → Er zeigt ______ ______.
c) Wir schenken dem Kind den Ball. → Wir schenken ______ ______.
d) Ich schicke meinem Bruder eine E-Mail. → Ich schicke ______ ______.

**4. Dative-only or two-object?** Complete with the correct pronoun.

a) Ich helfe ______ (du).
b) Ich danke ______ (Sie).
c) Das gefällt ______ (ich).
d) Ich gebe ______ (du) das Buch.
e) Die Schuhe passen ______ (er) nicht.
f) Er zeigt ______ (wir) die Stadt.

**5. Build a sentence.**

a) mein Vater / mir / ein Fahrrad / kauft → ______
b) kannst / mir / du / helfen → ______ (question)
c) ich / dir / die Wahrheit / sage → ______
d) das / gehört / nicht / mir → ______

**6. Fix the mistake.**

a) Ich gebe das Buch dem Mann. (what is wrong with this order?)
b) Ich helfe dich.
c) Er zeigt mir den Weg. (is this correct?)
d) Ich danke du.
e) Sie schenkt dem Kind den Ball. (is this correct?)

### Answer key

**1.**
a) dem Mann, das Buch
b) der Frau, den Weg
c) dem Kind, den Ball
d) meinem Freund, eine E-Mail
e) den Studenten, die Regel

**2.**
a) Ich gebe dem Mann das Buch.
b) Er zeigt mir den Weg.
c) Ich schicke ihr eine E-Mail.
d) Wir geben dir das Geschenk.

**3.**
a) Ich gebe es ihm. (accusative pronoun `es` before dative pronoun `ihm`)
b) Er zeigt ihn ihr. (accusative `ihn` before dative `ihr`)
c) Wir schenken es ihm.
d) Ich schicke sie ihm.

**4.**
a) dir
b) Ihnen
c) mir
d) dir
e) ihm
f) uns

**5.**
a) Mein Vater kauft mir ein Fahrrad.
b) Kannst du mir helfen?
c) Ich sage dir die Wahrheit.
d) Das gehört nicht mir. (or `Das gehört mir nicht`)

**6.**
a) The order is acceptable but unusual. Standard order is `Ich gebe dem Mann das Buch` (dative first). The version given puts the accusative first, which is only for emphasis.
b) Ich helfe **dir**. (helfen = dative)
c) Correct. `Er zeigt mir den Weg` is right: dative pronoun, accusative noun.
d) Ich danke **dir**.
e) Correct. `Sie schenkt dem Kind den Ball`: dative person, accusative thing.

## Pronunciation note

In fast speech, `gebe ich` can blend. Practise `Ich gebe ihm das Buch` and `Ich gebe es ihm` until the pronoun order feels automatic.

## Common mistakes

- Wrong: `Ich helfe dich`. Right: `Ich helfe dir`. helfen takes the dative.
- Wrong: putting the accusative before the dative when both are nouns. Right: person first: `Ich gebe dem Mann das Buch`.
- Wrong: `Ich gebe ihm es`. Right: when both are pronouns, accusative first: `Ich gebe es ihm`.
- Wrong: guessing the case of a new verb. Right: check the dictionary, it lists `+Dat` or `+Akk`.
