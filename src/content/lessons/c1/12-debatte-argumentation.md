# Lektion 12: Debatte und Argumentation

**Level:** C1 | **Target time:** 30 minutes, repeat over 3 sessions | **Status:** not started

---

## Goal

Argue a position at an advanced level: build a case, refute objections, and engage with counter-arguments in a debate.

## Why this matters

C1 requires you to argue **at length and with sophistication**, not just state an opinion. The speaking exam includes a discussion; academic and professional life require debate. This lesson builds the rhetorical toolkit: structuring an argument, anticipating objections, and rebutting them.

## Material

### The anatomy of an argument

| Element | Function | Example |
|---|---|---|
| These (claim) | what you assert | Online learning is effective. |
| Argument | the reason | Because it allows flexibility. |
| Beleg (evidence) | the support | Studies show higher completion rates. |
| Beispiel | the illustration | For example, in my own experience... |
| Schlussfolgerung | the conclusion | Therefore it should be promoted. |

### The argumentation structure (Toulmin model)

| Element | Function |
|---|---|
| Behauptung (claim) | the position |
| Begründung (grounds) | the evidence |
| Schlussregel (warrant) | the link between them |
| Stützung (backing) | support for the warrant |
| Einschränkung (qualifier) | the limits |
| Gegenargument (rebuttal) | the exception |

### Building an argument: the phrases

| Function | Phrase |
|---|---|
| Claim | Meiner Meinung nach... / Ich vertrete die Position, dass... |
| Grounds | Dies lässt sich damit begründen, dass... |
| Evidence | Studien zeigen, dass... / Zahlen belegen, dass... |
| Example | Ein Beispiel hierfür ist... |
| Warrant | Daraus folgt, dass... |
| Qualifier | Dies gilt allerdings nur, wenn... |
| Conclusion | Aus diesen Gründen... |

### Anticipating objections

Skilled arguers address counter-arguments before the opponent raises them.

| Function | Phrase |
|---|---|
| Concede | Zwar ist es richtig, dass... |
| Concede then refute | Es stimmt, dass X. Allerdings... |
| Anticipate | Man könnte einwenden, dass... |
| Refute | Dieses Argument greift jedoch zu kurz, weil... |
| Reject | Diese Annahme lässt sich widerlegen, denn... |
| Distinguish | Hier muss man differenzieren: ... |

### Refutation techniques

| Technique | Example |
|---|---|
| Rebut the evidence | Die zitierte Studie ist nicht repräsentativ. |
| Rebut the warrant | Der Schluss ist nicht zwingend. |
| Counter-example | Im Gegenteil: In Japan zeigt sich das Gegenteil. |
| Reinterpret | Das Ergebnis lässt sich anders erklären. |
| Distinguish | Das gilt für X, nicht aber für Y. |
| Reduce to absurdity | Konsequent zu Ende gedacht würde das bedeuten... |

### The concession structure

A strong C1 argument concedes then refutes.

`**Zwar** ist es richtig, dass Online-Kurse den persönlichen Kontakt reduzieren. **Allerdings** ermöglichen sie Menschen den Zugang, die sonst nicht studieren könnten. **Aus diesem Grund** überwiegen die Vorteile.`

(It is true that online courses reduce personal contact. However, they give access to people who otherwise could not study. For this reason the advantages outweigh.)

### Debate strategies

| Strategy | Description |
|---|---|
| Framing | Define the terms in your favour |
| Structuring | Number your points |
| Signposting | Announce what comes next |
| Conceding | Accept a point to build credibility |
| Reframing | Shift to a ground you control |
| Summarising | Restate your position at the end |

### Debate phrases: taking the floor

| Function | Phrase |
|---|---|
| Opening | Ich möchte zunächst auf einen zentralen Punkt eingehen. |
| Structuring | Erstens..., zweitens..., drittens... |
| Emphasising | Entscheidend ist dabei... |
| Adding | Darüber hinaus ist zu bedenken, dass... |
| Conceding | Ich räume ein, dass... |
| Refuting | Dem ist entgegenzuhalten, dass... |
| Concluding | Zusammenfassend lässt sich sagen, dass... |

### Debate phrases: reacting

| Function | Phrase |
|---|---|
| Agreeing | Dem stimme ich uneingeschränkt zu. |
| Partly agreeing | In diesem Punkt stimme ich zu, jedoch... |
| Disagreeing | Diese Auffassung teile ich nicht. |
| Requesting evidence | Worauf stützt sich diese Behauptung? |
| Challenging | Das setzt allerdings voraus, dass... |
| Interrupting | Gestatten Sie mir eine Zwischenbemerkung. |

### Logical fallacies to recognise

| Fallacy | Description |
|---|---|
| Strohmann | Misrepresenting the opponent |
| Ad hominem | Attacking the person |
| Falsche Dichotomie | Only two options |
| Zirkelschluss | Circular reasoning |
| Autoritätsargument | Appeal to authority |
| Verallgemeinerung | Overgeneralisation |

**Recognising fallacies helps you refute them.**

### Hedging and strength

| Weak | Strong |
|---|---|
| Ich denke vielleicht... | Ich bin überzeugt, dass... |
| Das könnte sein... | Es spricht viel dafür, dass... |
| Man sagt, dass... | Die Daten belegen, dass... |

**C1 argumentation is confident but hedged where evidence is limited.**

### The structure of a full argumentative text

1. **Einleitung:** topic, thesis
2. **Argument 1:** claim + grounds + evidence
3. **Argument 2:** claim + grounds + evidence
4. **Gegenargument:** concede + refute
5. **Schluss:** restate, conclude

### Practical C1 rules

1. **State the thesis clearly** at the start.
2. **Support each claim** with grounds and evidence.
3. **Anticipate and refute** the counter-argument.
4. **Concede** where the opponent is right, to build credibility.
5. **Hedge** where the evidence is limited.
6. **Signpost** so the listener can follow.

## Exercises

**1. Identify the element.**

a) "Online-Lernen ist effektiv." → ______
b) "Studien zeigen höhere Abschlussraten." → ______
c) "Daraus folgt, dass es gefördert werden sollte." → ______

**2. Concession structure.**

Complete: ______ ist es richtig, dass Online-Kurse den Kontakt reduzieren. ______ ermöglichen sie Zugang. ______ überwiegen die Vorteile.
(Zwar / Allerdings / Aus diesem Grund)

**3. Anticipating objections.**

a) Man könnte ______ , dass... (einwenden)
b) Dieses Argument ______ jedoch zu kurz. (greifen)
c) Hier muss man ______ . (differenzieren)

**4. Refutation techniques.**

a) "Die zitierte Studie ist nicht repräsentativ." → technique?
b) "Das Ergebnis lässt sich anders erklären." → technique?
c) "Im Gegenteil: In Japan zeigt sich das Gegenteil." → technique?

**5. Hedge or strengthen?**

a) "Ich denke vielleicht..." → weak / strong?
b) "Die Daten belegen, dass..." → weak / strong?
c) "Es spricht viel dafür, dass..." → weak / strong?

**6. Translate into German.**

a) In my opinion...
b) This can be justified by the fact that...
c) It is true that X. However...
d) This argument falls short because...
e) For these reasons...
f) In summary, it can be said that...

**7. Structure a full argument.**

Put in order: a) Gegenargument, b) Einleitung, c) Argument 1, d) Schluss, e) Argument 2.

**8. Fix the mistake.**

a) Attacking the person (ad hominem) instead of the argument.
b) No counter-argument addressed.
c) Overhedging: `Ich denke vielleicht, dass es eventuell sein könnte...`
d) No structure; points in random order.

### Answer key

**1.**
a) claim (These)
b) evidence (Beleg)
c) conclusion (Schlussfolgerung)

**2.**
Zwar ist es richtig, dass... Allerdings ermöglichen sie Zugang. Aus diesem Grund überwiegen die Vorteile.

**3.**
a) einwenden
b) greift
c) differenzieren

**4.**
a) rebut the evidence
b) reinterpret
c) counter-example

**5.**
a) weak
b) strong
c) strong (moderately)

**6.**
a) Meiner Meinung nach...
b) Dies lässt sich damit begründen, dass...
c) Zwar ist es richtig, dass X. Allerdings...
d) Dieses Argument greift zu kurz, weil...
e) Aus diesen Gründen...
f) Zusammenfassend lässt sich sagen, dass...

**7.**
b) Einleitung
c) Argument 1
e) Argument 2
a) Gegenargument
d) Schluss

**8.**
a) Attack the argument, not the person.
b) Anticipate and refute the counter-argument.
c) Hedge once, not three times.
d) Follow the structure.

## Pronunciation note

In a debate, stress the key claim: `EntSCHEIdend ist dabei...`. Pause before your counter-argument to signal the turn. Keep a steady, confident pace.

## Common mistakes

- Wrong: no clear thesis.
- Wrong: claims without evidence.
- Wrong: ignoring the counter-argument.
- Wrong: ad hominem attacks.
- Wrong: overhedging, which weakens your position.
