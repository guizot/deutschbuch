# Lektion 05: Textkohärenz und fortgeschrittene Konnektoren

**Level:** C1 | **Target time:** 30 minutes, repeat over 3 sessions | **Status:** not started

---

## Goal

Write texts that hold together, using the full range of cohesive devices: connectors, references, thematic progression, and paragraph structure.

## Why this matters

At C1, examiners and readers judge not just sentences but **texts**. Cohesion is what turns correct sentences into a readable argument. German has a rich inventory of cohesive devices, and using them well is what separates a B2 text from a C1 text.

---

## Material

### What cohesion means

**Cohesion** = the surface links between sentences (connectors, pronouns, references).
**Coherence** = the logical thread of meaning (does the argument make sense).

Both matter. This lesson focuses on the devices that create them.

### The five cohesive devices

| Device | Function | Example |
|---|---|---|
| Connectors | link clauses | deshalb, außerdem |
| Pronouns | refer back | er, sie, es, dieser |
| Reference words | point back | dies, jenes, solches |
| Lexical cohesion | repeat with variation | das Problem → diese Schwierigkeit |
| Thematic progression | build topic chains | Thema → Rhema |

### Connector inventory by function

| Function | Connectors |
|---|---|
| Addition | außerdem, zudem, darüber hinaus, ferner, des Weiteren |
| Contrast | allerdings, jedoch, hingegen, im Gegensatz dazu, demgegenüber |
| Cause | weil, da, denn, aufgrund, infolge |
| Consequence | deshalb, folglich, demnach, infolgedessen, also |
| Concession | obwohl, trotzdem, dennoch, gleichwohl, wenngleich |
| Purpose | damit, um...zu, zwecks |
| Condition | wenn, falls, sofern, es sei denn |
| Manner | indem, dadurch dass |
| Time | als, wenn, nachdem, bevor, während, seit |
| Alternative | oder, beziehungsweise, anstatt, statt |
| Summary | zusammenfassend, abschließend, insgesamt |
| Example | zum Beispiel, etwa, so |
| Emphasis | besonders, vor allem, insbesondere, gerade |
| Restriction | insofern, inwiefern, sofern |

### Position rules (review)

| Type | Word order | Examples |
|---|---|---|
| Coordinating | position 2 | deshalb, trotzdem, außerdem, jedoch |
| Subordinating | verb at the end | weil, obwohl, damit, indem |
| Prepositional | genitive phrase | wegen, trotz, aufgrund |

### Reference words

These point back to earlier content.

| Word | Use |
|---|---|
| dieser/diese/dieses | this (points to the nearest) |
| jener/jene/jenes | that (points to the farther) |
| derselbe/dieselbe | the same |
| solcher/solche | such |
| der/die/das (as pronoun) | the one, that |
| dergleichen | such things |
| Letzteres/Ersteres | the latter / the former |

`Die Regierung hat reagiert. **Diese** Maßnahme war umstritten.` (The government reacted. This measure was controversial.)
`Man kann studieren oder arbeiten. **Letzteres** ist schwieriger.` (One can study or work. The latter is harder.)

### Lexical cohesion: repetition with variation

Good German does not repeat the same word mechanically; it varies.

| Repetition | Variation |
|---|---|
| das Problem | die Schwierigkeit, die Herausforderung |
| die Firma | das Unternehmen, der Betrieb, der Konzern |
| die Menschen | die Bevölkerung, die Bürger, die Leute |
| wichtig | bedeutsam, wesentlich, relevant |
| sagen | erklären, betonen, anmerken |

### Thematic progression (Thema-Rhema)

Each sentence has a **Thema** (known information, at the start) and a **Rhema** (new information).

`Die Firma **hat ein neues Produkt entwickelt**. **Dieses Produkt** wird nächsten Monat **auf den Markt kommen**.`

Sentence 1: Thema = die Firma; Rhema = ein neues Produkt.
Sentence 2: Thema = dieses Produkt (the Rhema of sentence 1).

**This chaining creates a smooth text.** Break it and the text feels choppy.

### Paragraph structure

A C1 paragraph has:
1. **Topic sentence** (states the main idea)
2. **Support** (evidence, examples, reasoning)
3. **Link** (transition to the next paragraph)

### Paragraph connectors

| Function | Phrase |
|---|---|
| Introduce topic | Was ... betrifft, ... / Hinsichtlich ... |
| Add | Darüber hinaus ... / Zudem ... |
| Contrast | Im Gegensatz dazu ... / Allerdings ... |
| Conclude paragraph | Somit ... / Damit ... |
| Open new paragraph | Ein weiterer Aspekt ... / Ebenso wichtig ... |

### Common cohesion errors

| Error | Fix |
|---|---|
| Repeating the same noun every sentence | Vary with synonyms/pronouns |
| No connectors between sentences | Add deshalb, außerdem, jedoch |
| Jumping between topics | Chain Thema → Rhema |
| Using the wrong connector type | Match the logical relationship |
| Overusing one connector | Rotate the inventory |

### A model cohesive paragraph

`**Was den Klimawandel betrifft**, sind sich die Forscher weitgehend einig. **Darüber hinaus** zeigen aktuelle Studien, dass die Folgen schneller eintreten als erwartet. **Allerdings** gibt es unterschiedliche Einschätzungen, wie schnell gehandelt werden muss. **Dennoch** ist der Handlungsbedarf unbestritten. **Aus diesen Gründen** fordern viele Experten eine schnelle Reduktion der Emissionen.`

(Regarding climate change, researchers largely agree. Moreover, current studies show that the consequences are arriving faster than expected. However, there are different assessments of how quickly action is needed. Nevertheless, the need for action is undisputed. For these reasons, many experts call for a rapid reduction in emissions.)

**Notice:** every sentence links to the previous one through a connector or a reference.

### Practical C1 rules

1. **Use a connector** between most sentences in formal writing.
2. **Rotate the inventory**; do not overuse one word.
3. **Vary nouns** with synonyms and pronouns.
4. **Chain Thema → Rhema** so each sentence picks up the previous.
5. **Give each paragraph** a topic sentence and a link.

## Exercises

**1. Choose the right connector.**

a) Addition: außerdem / trotzdem → ______
b) Contrast: jedoch / deshalb → ______
c) Consequence: folglich / obwohl → ______
d) Concession: dennoch / zudem → ______

**2. Coordinating or subordinating?**

a) deshalb → ______
b) obwohl → ______
c) außerdem → ______
d) indem → ______
e) jedoch → ______

**3. Reference words.**

a) Die Regierung hat reagiert. ______ Maßnahme war umstritten. (this)
b) Man kann studieren oder arbeiten. ______ ist schwieriger. (the latter)

**4. Vary the noun.**

a) das Problem → ______ , ______
b) die Firma → ______ , ______
c) die Menschen → ______ , ______

**5. Thema-Rhema chain.** Put the sentences in a smooth order.

a) Dieses Produkt wird nächsten Monat auf den Markt kommen.
b) Die Firma hat ein neues Produkt entwickelt.
c) Der Markt reagiert oft positiv auf Innovationen.

**6. Translate into German.**

a) Regarding climate change, researchers largely agree.
b) Moreover, current studies show that...
c) However, there are different assessments.
d) Nevertheless, the need for action is undisputed.
e) For these reasons, many experts call for action.

**7. Improve the cohesion.**

a) (Three sentences with no connectors) → add connectors.

**8. Fix the mistake.**

a) Overusing `deshalb` in every sentence.
b) Repeating `die Firma` in every sentence.
c) Jumping between topics without Thema-Rhema chaining.
d) Using `weil` where `deshalb` is meant (word order confusion).

### Answer key

**1.**
a) außerdem
b) jedoch
c) folglich
d) dennoch

**2.**
a) coordinating
b) subordinating
c) coordinating
d) subordinating
e) coordinating

**3.**
a) Diese
b) Letzteres

**4.**
a) die Schwierigkeit, die Herausforderung
b) das Unternehmen, der Betrieb
c) die Bevölkerung, die Bürger

**6.**

b) Darüber hinaus zeigen aktuelle Studien, dass...
c) Allerdings gibt es unterschiedliche Einschätzungen.

**7.**
Add `darüber hinaus`, `allerdings`, `dennoch` between the sentences, and vary the nouns.

a) Rotate the connectors.
b) Vary with synonyms (das Unternehmen, der Betrieb).
c) Chain each sentence's Thema to the previous Rhema.
d) `weil` → verb at the end; `deshalb` → verb in position 2.

## Pronunciation note

Connectors are usually unstressed in speech; the stress falls on the content word: `Deshalb BLEIbe ich zu Hause`. Pause slightly at paragraph transitions.

## Common mistakes

- Wrong: no connectors; sentences feel disconnected.
- Wrong: overusing one connector.
- Wrong: repeating the same noun.
- Wrong: no Thema-Rhema chaining.
- Wrong: mixing coordinating and subordinating word order.
