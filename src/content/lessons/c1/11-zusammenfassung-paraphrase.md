# Lektion 11: Zusammenfassen und Paraphrasieren

**Level:** C1 | **Target time:** 30 minutes, repeat over 3 sessions | **Status:** not started

---

## Goal

Summarise a text concisely and paraphrase it in your own words, without distorting the meaning.

## Why this matters

Summarising and paraphrasing are core C1 skills, tested directly in exams (summarise a text, write an abstract) and required constantly at university. They demand three things at once: comprehension, compression, and independent wording. This is where many learners lose marks by copying the original.

---

## Material

### Summary vs paraphrase

| Skill | What it does | Length |
|---|---|---|
| **Zusammenfassung** | condenses the whole text | much shorter |
| **Paraphrase** | restates a passage in new words | similar length |

Both require **your own wording**, not the original's.

### The rules of a summary

1. **Shorter** than the original (often one-third or less).
2. **Own words** — no copying of phrases.
3. **Essential content only** — drop examples, repetitions, asides.
4. **Neutral** — no personal opinion.
5. **Present tense** — summaries are written in the present.
6. **Logical order** — follow the original's argument.

### The structure of a summary

| Part | Content |
|---|---|
| Einleitungssatz | author, title, text type, topic |
| Hauptteil | the main points in order |
| Schluss | the conclusion or aim |

`Der Artikel "..." von [Autor] aus dem Jahr [Jahr] behandelt [Thema]. Der Autor argumentiert, dass... Abschließend kommt er zu dem Ergebnis, dass...`

### The opening sentence

| Phrase | Meaning |
|---|---|
| Der Text "..." von ... behandelt... | The text "..." by ... deals with... |
| In dem Artikel geht es um... | The article is about... |
| Der Autor beschäftigt sich mit... | The author deals with... |
| Der vorliegende Text thematisiert... | The present text addresses... |
| Die Autorin argumentiert, dass... | The author argues that... |

### Reporting the content

| Phrase | Meaning |
|---|---|
| Zunächst wird dargestellt, dass... | First it is shown that... |
| Der Autor weist darauf hin, dass... | The author points out that... |
| Im Weiteren wird erläutert, wie... | Furthermore it is explained how... |
| Der Text kommt zu dem Ergebnis, dass... | The text concludes that... |
| Abschließend betont der Autor, dass... | Finally the author emphasises that... |

### The Konjunktiv I in summaries

Reporting someone else's text uses the Konjunktiv I.

`Der Autor **betont**, die Maßnahme **sei** notwendig.`
`Er **argumentiert**, die Daten **ließen** sich verallgemeinern.`

### Paraphrasing techniques

| Technique | Example |
|---|---|
| Synonym substitution | wichtig → bedeutsam |
| Change word class | wichtig → von Bedeutung |
| Change voice | Man prüft die Daten → Die Daten werden geprüft |
| Change structure | Weil X, Y → Wegen X, Y |
| Generalise | Autos, Busse, Züge → Verkehrsmittel |
| Specify | Tiere → Hunde und Katzen |

### Worked paraphrase

**Original:** `Weil die Preise in den letzten Jahren stark gestiegen sind, können sich viele Menschen das Wohnen in der Stadt nicht mehr leisten.`

**Paraphrase:** `Aufgrund des deutlichen Preisanstiegs in den vergangenen Jahren ist städtisches Wohnen für viele unbezahlbar geworden.`

Changes: `weil` → `aufgrund`; `stark gestiegen` → `deutlicher Preisanstieg`; `in den letzten Jahren` → `in den vergangenen Jahren`; `können sich nicht leisten` → `ist unbezahlbar`.

### Compression techniques

| Technique | Example |
|---|---|
| Generalise | Beispiele weglassen |
| Merge sentences | Two short → one long |
| Nominalise | weil X → wegen X |
| Drop redundancy | Repetitions out |
| Keep key terms | Zahlen, Namen, Kernaussagen |

### What to keep and what to cut

| Keep | Cut |
|---|---|
| Main argument | Examples (unless essential) |
| Key data | Repetitions |
| Conclusion | Anecdotes |
| Structure markers | Digressions |
| Author's stance | Rhetorical flourishes |

### Common summary errors

| Error | Fix |
|---|---|
| Copying phrases from the original | Paraphrase |
| Too long | Cut to the essentials |
| Personal opinion | Stay neutral |
| Wrong tense | Use the present |
| Missing the main point | Identify the thesis first |
| Distorting the meaning | Check against the original |

### Academic abstract

An abstract is a formal summary of a paper.

| Move | Phrase |
|---|---|
| Context | Die Arbeit befasst sich mit... |
| Aim | Ziel ist es, zu untersuchen... |
| Method | Die Untersuchung erfolgte mittels... |
| Results | Die Ergebnisse zeigen, dass... |
| Conclusion | Daraus folgt, dass... |

### Practical C1 rules

1. **Identify the thesis** before writing.
2. **Use your own words** throughout.
3. **Stay neutral** — no opinion.
4. **Write in the present tense.**
5. **Follow the original's order.**
6. **Check the meaning** against the original.

## Pronunciation note

In an oral summary, signpost clearly: `ZUNÄCHST ... DARÜBER HINAUS ... ABSCHLIEßEND`. The signposts help the listener follow your compression.

## Common mistakes

- Wrong: copying phrases from the original.
- Wrong: writing too long a summary.
- Wrong: inserting personal opinion.
- Wrong: using the past tense.
- Wrong: losing the author's main point.
