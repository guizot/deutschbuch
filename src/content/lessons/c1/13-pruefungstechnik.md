# Lektion 13: Prüfungstechnik — Alle vier Module

**Level:** C1 | **Target time:** 30 minutes, repeat over 2 sessions | **Status:** not started

---

## Goal

Know the C1 exam formats and use module-specific techniques to maximise your score.

## Why this matters

C1 is your gateway to university and to regulated professions. The exam tests the same four skills as B2 but at a higher level, with longer texts, more complex tasks, and stricter assessment. Knowing the format and the techniques turns preparation into a targeted effort instead of a vague one.

### Goethe C1: the four modules

| Module | Time | Parts |
|---|---|---|
| Lesen | 65 min | 4 parts |
| Hören | 40 min | 2 parts |
| Schreiben | 80 min | 2 tasks |
| Sprechen | ~15 min | 2 parts (presentation + discussion) |

### Lesen (reading) at C1

**What it tests:** demanding texts, implicit meaning, argument structure, register.

**Techniques:**
1. **Skim for gist** (2 min), then read the questions.
2. **Identify the thesis** of each paragraph.
3. **Watch for implicit meaning** — C1 asks what the author implies, not just states.
4. **Note the register**: is the author ironic, critical, neutral?
5. **Watch for the Konjunktiv I** — it signals reported, not endorsed, claims.
6. **Never leave blank.**

**C1-specific challenge:** distinguishing the author's opinion from a reported opinion. `Der Minister behauptet, X sei Y` means the journalist reports but does not endorse.

### Hören (listening) at C1

**What it tests:** long conversations, lectures, interviews, with implicit meaning.

**Techniques:**
1. **Read the questions in the pause.**
2. **Note the speaker's attitude**, not just the facts.
3. **Watch for irony and understatement.**
4. **Note modal particles** (doch, ja, denn) that signal attitude.
5. **Follow the argument structure.**
6. **Never leave blank.**

### Schreiben (writing) at C1

**Task 1:** a formal text (letter, email, report) — often a response or a complaint.
**Task 2:** an argumentative text (essay, article, contribution).

**Techniques:**
1. **Plan 5-7 minutes** before writing.
2. **Use the standard structure** for the text type.
3. **Answer every content point** in the task.
4. **Use the C1 toolkit:** nominalisation, connectors, Konjunktiv I for reporting, hedging.
5. **Keep the register consistent.**
6. **Reserve 5-7 minutes** to check cases, verb positions, collocations, and register.

**Marking criteria:** task fulfilment, coherence, vocabulary range, grammatical accuracy, register.

**C1-specific challenge:** the examiner looks for **range** — varied structures, precise vocabulary, appropriate register.

### Sprechen (speaking) at C1

**Part 1:** a presentation (usually on a complex topic, with structure).
**Part 2:** a discussion with a partner.

**Techniques:**
1. **Structure the presentation** explicitly (Einleitung, Gliederung, Hauptteil, Schluss).
2. **Use signposting** so the examiner can follow.
3. **Hedge and qualify** — C1 expects nuance.
4. **In the discussion**, engage, concede, and refute (use the Lektion 12 toolkit).
5. **Keep going** — fluency and interaction matter more than perfection.
6. **Do not memorise a script.**

### General strategy

| Principle | Detail |
|---|---|
| Know the format | Practise with real past papers |
| Time budget | Allocate minutes; stick to them |
| Never blank | Guess if unsure |
| Read the task twice | Half the errors are task misreads |
| Register | Match the text type |
| Range | Show varied structures and vocabulary |
| Check | Reserve 5-7 minutes |

### The C1 "range" principle

At C1, examiners reward **variety**, not repetition.

| Weak (B2 level) | Strong (C1 level) |
|---|---|
| Uses `weil` every time | Uses weil, da, aufgrund, infolge |
| Simple verbs | Mixes simple verbs with Funktionsverbgefüge |
| Active only | Mixes active and passive |
| No hedging | Hedges appropriately |
| One register | Switches register deliberately |

### TestDaF specifics (for university)

| Part | Note |
|---|---|
| Leseverstehen | 3 tasks |
| Hörverstehen | 3 tasks |
| Schriftlicher Ausdruck | 1 task (graph description + argument) |
| Mündlicher Ausdruck | 7 tasks, recorded |
| Grading | TDN 3, 4, or 5 |

**TestDaF is academic.** Learn the vocabulary of your field and practise the graph description task (a distinctive TestDaF format).

### The DSH

| Part | Note |
|---|---|
| Hörverstehen | 1 task |
| Leseverstehen | 1 task |
| Textproduktion | 1 task |
| Grammatik | a separate section |
| Mündliche Prüfung | after passing the written |

**DSH includes an explicit grammar section** — rare among modern exams.

### Practical C1 rules

1. **Practise with real past papers**, timed, under exam conditions.
2. **Plan writing tasks** for 5-7 minutes.
3. **Show range** — vary structures and vocabulary.
4. **Never leave a blank.**
5. **Match the register** to the text type.
6. **For university**, plan for TestDaF or DSH.

## Exercises

**1. Which module?**

a) You read demanding texts and identify implicit meaning. → ______
b) You listen to a lecture and note the speaker's attitude. → ______
c) You write a formal text and an argumentative text. → ______
d) You give a presentation and discuss. → ______

**2. Technique check.**

a) In Lesen, what does the Konjunktiv I signal? → ______
b) In Schreiben, how long should you plan? → ______
c) In Sprechen, should you memorise a script? → ______
d) In all modules, should you leave blanks? → ______

**3. Which exam for university?**

a) Goethe C1 → ______
b) TestDaF → ______
c) DSH → ______

**4. Range: weak or strong C1?**

a) Uses `weil` every time → ______
b) Mixes weil, da, aufgrund, infolge → ______
c) No hedging → ______
d) Hedges appropriately → ______

**5. Match the exam to the feature.**

a) Has a separate grammar section → ______
b) Has a graph description task → ______
c) Modular, four skills → ______

**6. Translate into German.**

a) I have to practise with real past papers.
b) I plan the writing task for five to seven minutes.
c) I must show range in my writing.
d) Never leave a blank.
e) For university I need TestDaF or DSH.

**7. Fix the mistake (exam strategy).**

a) Starting to write immediately.
b) Using the same connector throughout.
c) Memorising a presentation script.
d) Ignoring the counter-argument in the discussion.

### Answer key

**1.**
a) Lesen
b) Hören
c) Schreiben
d) Sprechen

**2.**
a) It signals a reported claim, not the writer's endorsement.
b) 5-7 minutes.
c) No — use a structure.
d) No — never leave blank.

**3.**
a) Accepted by some universities, but TestDaF/DSH are more standard
b) Yes
c) Yes

**4.**
a) weak
b) strong
c) weak
d) strong

**5.**
a) DSH
b) TestDaF
c) Goethe C1

**6.**
a) Ich muss mit echten Modellsätzen üben.
b) Ich plane die Schreibaufgabe fünf bis sieben Minuten lang.
c) Ich muss in meinem Text Bandbreite zeigen.
d) Niemals leer lassen.
e) Für die Universität brauche ich TestDaF oder DSH.

**7.**
a) Plan first (5-7 minutes).
b) Vary the connectors (weil, da, aufgrund, infolge).
c) Use a structure; do not memorise a script.
d) Address and refute the counter-argument.

## Common mistakes

- Wrong: not practising with real past papers.
- Wrong: poor time management.
- Wrong: leaving blanks.
- Wrong: no range; repeating the same structures.
- Wrong: mismatching register.
- Wrong: memorising a presentation.
