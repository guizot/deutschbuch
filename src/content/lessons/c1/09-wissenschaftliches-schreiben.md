# Lektion 09: Wissenschaftliches Schreiben

**Level:** C1 | **Target time:** 30 minutes, repeat over 3 sessions | **Status:** not started

---

## Goal

Write academic German: structure a paper, cite sources, report findings, and use the impersonal academic register.

## Why this matters

If you are going to study in Germany, this lesson is the practical core. Academic German has strict conventions for structure, citation, hedging, and impersonal style. Getting them right is the difference between a text that reads as student work and one that reads as scholarship.

## Material

### The structure of an academic text

| Section | Function |
|---|---|
| Titel | title |
| Abstract / Zusammenfassung | summary |
| Einleitung | introduction, question, aim |
| Forschungsstand | state of research |
| Methodik / Methode | method |
| Ergebnisse | results |
| Diskussion | discussion |
| Fazit / Schlussfolgerung | conclusion |
| Literaturverzeichnis | bibliography |

### The Einleitung (introduction)

| Move | Phrase |
|---|---|
| Topic | Die vorliegende Arbeit befasst sich mit... |
| Relevance | Das Thema ist von großer Bedeutung, weil... |
| Research gap | Bislang ist unklar, ob... |
| Question | Die Arbeit geht der Frage nach, inwiefern... |
| Aim | Ziel der Arbeit ist es, ... zu untersuchen. |
| Structure | Die Arbeit gliedert sich in drei Teile. |

`**Die vorliegende Arbeit befasst sich mit** den Folgen des Klimawandels. **Ziel ist es, zu untersuchen**, wie sich die Emissionen entwickelt haben. **Die Arbeit gliedert sich in** drei Teile.`

### The Methodik (method)

| Phrase | Meaning |
|---|---|
| Die Daten wurden mittels ... erhoben. | The data was collected by means of... |
| Zur Analyse wurde ... verwendet. | For the analysis, ... was used. |
| Die Stichprobe umfasst ... Personen. | The sample comprises ... people. |
| Es handelt sich um eine qualitative/quantitative Studie. | It is a qualitative/quantitative study. |
| Die Untersuchung erfolgte im Zeitraum von ... bis ... | The study took place between ... and ... |

### The Ergebnisse (results)

| Phrase | Meaning |
|---|---|
| Die Ergebnisse zeigen, dass... | The results show that... |
| Es zeigte sich, dass... | It emerged that... |
| Wie aus Tabelle 1 hervorgeht, ... | As Table 1 shows, ... |
| Die Analyse ergab, dass... | The analysis found that... |
| Auffällig ist, dass... | It is striking that... |

### The Diskussion (discussion)

| Phrase | Meaning |
|---|---|
| Die Ergebnisse deuten darauf hin, dass... | The results suggest that... |
| Dies lässt sich dadurch erklären, dass... | This can be explained by... |
| Im Gegensatz zu Müller (2020) zeigt die Studie, dass... | In contrast to Müller (2020), the study shows... |
| Einschränkend ist anzumerken, dass... | It should be noted as a limitation that... |
| Dies steht im Einklang mit... | This is consistent with... |

### The Fazit (conclusion)

| Phrase | Meaning |
|---|---|
| Zusammenfassend lässt sich festhalten, dass... | In summary, it can be stated that... |
| Die Untersuchung hat gezeigt, dass... | The study has shown that... |
| Aus den Ergebnissen folgt, dass... | From the results it follows that... |
| Weiterer Forschungsbedarf besteht hinsichtlich... | Further research is needed regarding... |

### Citation and reference language

| Phrase | Meaning |
|---|---|
| Laut Müller (2020) ... | According to Müller (2020)... |
| Müller (2020) zufolge ... | According to Müller (2020)... |
| Wie Müller (2020) betont, ... | As Müller (2020) emphasises,... |
| Vgl. Müller (2020), S. 15. | Compare Müller (2020), p. 15. |
| Vgl. ebd. | Compare ibid. |
| a.a.O. | at the cited place |

**Note the Konjunktiv I in reporting:** `Müller **betont**, die Methode **sei** effektiv.`

### Hedging: the academic caution

Academic German avoids absolute claims. Use hedging.

| Absolute (avoid) | Hedged |
|---|---|
| Das ist bewiesen. | Das **dürfte** bewiesen sein. |
| Alle Experten sagen... | **Viele** Experten **gehen davon aus**... |
| Das Ergebnis ist eindeutig. | Das Ergebnis **deutet darauf hin**... |
| Es ist klar, dass... | Es **lässt sich vermuten**, dass... |
| Das beweist... | Das **legt die Vermutung nahe**, dass... |

**Hedging verbs:** dürfte, scheint, deutet darauf hin, lässt vermuten, ist anzunehmen, spricht dafür.

### The impersonal academic register

| Personal (avoid) | Impersonal |
|---|---|
| Ich habe festgestellt, dass... | Es wurde festgestellt, dass... |
| Ich denke, dass... | Es ist anzunehmen, dass... |
| Wir haben analysiert... | Die Analyse erfolgte... |
| Man kann sagen, dass... | Es lässt sich sagen, dass... |

**Rule:** avoid `ich` and `wir` in academic writing; use the passive or impersonal constructions.

### The academic impersonal phrases

| Phrase | Meaning |
|---|---|
| es ist anzunehmen, dass | it is to be assumed that |
| es ist festzustellen, dass | it is to be noted that |
| es gilt zu beachten, dass | it is important to note that |
| es lässt sich sagen, dass | it can be said that |
| es zeigt sich, dass | it emerges that |
| es ist davon auszugehen, dass | it is to be assumed that |
| es sei darauf hingewiesen, dass | it should be pointed out that |

### Nominalstil in academic writing

Academic German is nominal. Review the transformation.

`Weil die Preise stiegen, sank der Verbrauch.` → `Aufgrund des Preisanstiegs sank der Verbrauch.`

### Connectors in academic writing

| Function | Connector |
|---|---|
| Addition | darüber hinaus, ferner, zudem |
| Contrast | hingegen, im Gegensatz dazu, allerdings |
| Cause | aufgrund, infolge, da |
| Consequence | folglich, demnach, infolgedessen |
| Concession | wenngleich, obgleich, dennoch |
| Summary | zusammenfassend, abschließend |

### Common academic collocations

| Collocation | Meaning |
|---|---|
| eine These vertreten | to maintain a thesis |
| eine Hypothese aufstellen | to formulate a hypothesis |
| Daten erheben | to collect data |
| eine Analyse durchführen | to conduct an analysis |
| ein Ergebnis erzielen | to achieve a result |
| Schlussfolgerungen ziehen | to draw conclusions |
| einen Nachweis erbringen | to provide proof |
| Kritik üben an | to criticise |
| Bezug nehmen auf | to refer to |

### Practical C1 rules

1. **Follow the standard structure** (Einleitung → Methodik → Ergebnisse → Diskussion → Fazit).
2. **Avoid `ich` and `wir`**; use impersonal constructions.
3. **Hedge** every strong claim.
4. **Use the Konjunktiv I** to report sources.
5. **Nominalise** for density, but keep it readable.
6. **Cite consistently** in one system (APA, MLA, Chicago, or the German standard).

## Pronunciation note

Academic German is spoken slowly and precisely. The impersonal phrases are stressed on the key word: `Es ist ANzunehmen, dass...`. Practise the hedging phrases until they are automatic.

## Common mistakes

- Wrong: using `ich`/`wir` in academic writing.
- Wrong: making absolute claims without hedging.
- Wrong: reporting sources without the Konjunktiv I.
- Wrong: no clear structure.
- Wrong: inconsistent citation system.
