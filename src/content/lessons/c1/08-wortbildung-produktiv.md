# Lektion 08: Produktive Wortbildung

**Level:** C1 | **Target time:** 30 minutes, repeat over 4 sessions | **Status:** not started

---

## Goal

Generate words productively using prefixes, suffixes, and compounding, so you can express ideas you have never memorised.

## Why this matters

At C1 you stop learning words one by one and start generating them. If you know the patterns, you can produce `Nachhaltigkeit`, `verstaatlichen`, `unüberwindbar` on the spot. This is the difference between a fixed vocabulary and a flexible one, and it is essential for academic and professional German.

---

## Material

### The principle

German word formation is **rule-governed**. Learn the rules and you can generate and decode words.

`nachhaltig` → `Nachhaltigkeit` → `nachhaltigerweise`
`überwinden` → `überwindbar` → `unüberwindbar`

### Noun formation: the productive suffixes

| Suffix | From | Gender | Example |
|---|---|---|---|
| -ung | verb | f | prüfen → Prüfung |
| -heit | adj | f | frei → Freiheit |
| -keit | adj | f | möglich → Möglichkeit |
| -igkeit | adj | f | nachhaltig → Nachhaltigkeit |
| -schaft | noun | f | Freund → Freundschaft |
| -tum | noun/adj | n | reich → Reichtum |
| -nis | verb/adj | n/f | ergebnis, Erlaubnis |
| -er | verb | m | forschen → Forscher |
| -ling | verb/adj | m | prüfen → Prüfling |
| -heit | noun | f | Mensch → Menschheit |

### Verb formation

| Suffix/prefix | From | Example |
|---|---|---|
| -ieren | noun | Telefon → telefonieren |
| -isieren | adj/noun | real → realisieren |
| -ifizieren | adj/noun | klar → klarifizieren (rare) |
| be- | noun/verb | Antrag → beantragen |
| ver- | adj/noun | Staat → verstaatlichen |
| er- | adj | möglich → ermöglichen |
| ent- | noun | Staat → entstaatlichen |
| -eln | verb | lachen → lächeln |

**Note:** `-ieren`, `-isieren` verbs take **no ge-** in the Partizip II.

`telefonieren → telefoniert`, `realisieren → realisiert`.

### Adjective formation

| Suffix | From | Example |
|---|---|---|
| -lich | noun/verb | Freund → freundlich |
| -ig | noun | Freude → freudig |
| -isch | noun | Kind → kindisch |
| -bar | verb | lösen → lösbar |
| -sam | verb | sparen → sparsam |
| -haft | noun | Leben → lebhaft |
| -los | noun | Arbeit → arbeitslos |
| -voll | noun | Sinn → sinnvoll |
| -arm | noun | Wasser → wasserarm |
| -reich | noun | Wasser → wasserreich |
| -mäßig | noun | Plan → planmäßig |

### Negation with un-

`un-` negates adjectives and nouns.

| Positive | Negative |
|---|---|
| möglich | unmöglich |
| nötig | unnötig |
| sicher | unsicher |
| klar | unklar |
| glücklich | unglücklich |
| das Glück | das Unglück |
| die Sicherheit | die Unsicherheit |
| der Sinn | der Unsinn |

**But not everything takes un-:** `unwahrscheinlich` (correct), `ungut` (rare; usually `schlecht`).

### Compounding: the productive patterns

German creates new compounds freely.

| Pattern | Example | Meaning |
|---|---|---|
| Noun + noun | Umweltschutz | environmental protection |
| Verb stem + noun | Waschmaschine | washing machine |
| Adjective + noun | Großstadt | big city |
| Preposition + noun | Vorort | suburb |
| Noun + adjective | wasserreich | rich in water |
| Particle + verb | aufstehen | to get up |

### The gender rule (review)

The compound takes the gender of the **last** element.

`das Haus` → `das Krankenhaus`
`die Tür` → `die Haustür`
`der Schuh` → `der Handschuh`

| Suffix | Meaning | Example |
|---|---|---|
| -heit/-keit | quality | Freiheit, Möglichkeit |
| -ung | action/result | Prüfung |
| -schaft | collective/state | Freundschaft |
| -tum | state/domain | Reichtum, Königstum |

### The -weise adverbial suffix

Turns adjectives into adverbs.

| Adjective | Adverb |
|---|---|
| normal | normalerweise |
| möglich | möglicherweise |
| glücklich | glücklicherweise |
| interessant | interessanterweise |
| verständlich | verständlicherweise |
| Beispiel | beispielsweise |

`**Interessanterweise** stimmt das nicht.` (Interestingly, that is not true.)

### Nominalisation with -ung, -heit, -keit

These are the most productive; review the rules.

| Base | Suffix | Result |
|---|---|---|
| nachhaltig | -keit | Nachhaltigkeit |
| verfügbar | -keit | Verfügbarkeit |
| wirksam | -keit | Wirksamkeit |
| gleich | -heit | Gleichheit |
| entwickeln | -ung | Entwicklung |
| verwirklichen | -ung | Verwirklichung |

### Building new words: worked examples

| You want to say... | Build it |
|---|---|
| the quality of being sustainable | nachhaltig → Nachhaltigkeit |
| capable of being overcome | überwinden → überwindbar |
| not capable of being overcome | → unüberwindbar |
| to make something state-owned | Staat → verstaatlichen |
| the process of making state-owned | → Verstaatlichung |
| in a manner that can be understood | verstehen → verständlicherweise |

### Productive patterns in academic German

| Pattern | Example | Meaning |
|---|---|---|
| -ung | die Umsetzung | implementation |
| -keit | die Wirksamkeit | effectiveness |
| -barkeit | die Nachweisbarkeit | provability |
| -losigkeit | die Arbeitslosigkeit | unemployment |
| -mäßig | die Leistungsmäßig... | in terms of performance |
| ge-...-heit | die Gegebenheit | given fact |

### The "Substantivitis" warning

Productive formation makes it easy to over-nominalise. Use the patterns, but keep the text readable.

**Bad:** `Die Durchführbarkeit der Umsetzbarkeit der Verwirklichung...`
**Better:** break it up with verbal clauses.

### Practical C1 rules

1. **Learn the suffix → gender mapping** (-ung/-heit/-keit = f).
2. **Use un- for negation**, but check it exists.
3. **Compound gender = last element.**
4. **Use -weise for adverbs.**
5. **-ieren verbs take no ge-.**
6. **Generate words** rather than memorising every one.

## Pronunciation note

Productive suffixes are unstressed: `NachHALtigkeit`, `MÖGlichkeit`, `ARbeitslosigkeit`. The stress stays on the stem. In compounds, the first element is stressed: `UMweltschutz`.

## Common mistakes

- Wrong: `die möglichkeit` (lowercase). Right: `die Möglichkeit`.
- Wrong: adding ge- to -ieren verbs.
- Wrong: giving -ung/-heit/-keit nouns the wrong gender (all feminine).
- Wrong: assuming every adjective takes un-.
- Wrong: over-nominalising.
