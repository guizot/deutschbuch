# Lektion 17: Präsentation und Diskussion

**Level:** B2 | **Target time:** 30 minutes, repeat over 3 sessions | **Status:** not started

---

## Goal

Give a structured presentation and take part in a discussion using the right phrases and techniques.

## Why this matters

The B2 speaking exam has two parts: a presentation and a discussion. Beyond the exam, presentations and meetings are the everyday reality of working in Germany. This lesson gives you the frame and the phrases so you can focus on content, not on freezing.

---

## Material

### The B2 speaking exam structure

| Part | Task | Time |
|---|---|---|
| Teil 1 | Präsentation (short talk on a topic) | ~4 min |
| Teil 2 | Diskussion (discuss with a partner) | ~5 min |

You usually get a few minutes to prepare with notes.

### Part 1: The presentation

**Structure:**
1. **Einleitung** — topic, why it matters
2. **Gliederung** — what you will cover
3. **Hauptteil** — 2-3 points with examples
4. **Schluss** — summary, personal opinion
5. **Fragen** — invite questions

### Presentation phrases: opening

| Function | Phrase |
|---|---|
| Topic | Mein Thema heute ist... |
| Relevance | Das Thema ist wichtig, weil... |
| Personal link | Ich habe mich für dieses Thema entschieden, weil... |
| Outline | Ich möchte zuerst..., dann..., und schließlich... |
| Time | Ich werde etwa vier Minuten sprechen. |

`Mein Thema heute ist **Online-Lernen**. Ich habe mich dafür entschieden, weil ich selbst online lerne. Zuerst erkläre ich die Vorteile, dann die Nachteile, und schließlich gebe ich meine Meinung.`

### Presentation phrases: main part

| Function | Phrase |
|---|---|
| First point | Zuerst möchte ich... nennen. |
| Adding | Ein weiterer Punkt ist... |
| Example | Ein Beispiel dafür ist... |
| Statistics | Laut einer Studie... |
| Contrast | Im Gegensatz dazu... |
| Emphasising | Besonders wichtig ist... |
| Personal experience | Aus eigener Erfahrung kann ich sagen... |

### Presentation phrases: closing

| Function | Phrase |
|---|---|
| Summary | Zusammenfassend lässt sich sagen, dass... |
| Opinion | Meiner Meinung nach... |
| Conclusion | Abschließend möchte ich betonen, dass... |
| Inviting questions | Vielen Dank für Ihre Aufmerksamkeit. Haben Sie Fragen? |

### Handling questions

| Function | Phrase |
|---|---|
| Clarifying | Das ist eine gute Frage. |
| Buying time | Lass mich kurz nachdenken. |
| Rephrasing | Anders gesagt... |
| Admitting uncertainty | Da bin ich mir nicht sicher, aber ich denke... |
| Deferring | Darauf kann ich leider keine genaue Antwort geben. |

### Part 2: The discussion

**Structure:**
1. **Opening** — state your initial position
2. **Reacting** — respond to the partner
3. **Agreeing / disagreeing** — with reasons
4. **Building** — add new points
5. **Concluding** — summarise where you agree and differ

### Discussion phrases: stating position

| Function | Phrase |
|---|---|
| Opinion | Ich bin der Meinung, dass... |
| Certainty | Ich bin überzeugt, dass... |
| Uncertainty | Ich bin mir nicht sicher, ob... |
| Experience | Meiner Erfahrung nach... |

### Discussion phrases: reacting

| Function | Phrase |
|---|---|
| Agreeing | Da stimme ich dir zu. |
| Partly agreeing | Das sehe ich ähnlich, aber... |
| Disagreeing | Da bin ich anderer Meinung. |
| Asking | Wie siehst du das? |
| Interrupting politely | Entschuldigung, darf ich kurz etwas sagen? |
| Conceding | Das ist ein guter Punkt, allerdings... |

### Discussion phrases: building and concluding

| Function | Phrase |
|---|---|
| Adding | Dazu kommt, dass... |
| Giving example | Ein Beispiel wäre... |
| Softening | Man könnte argumentieren, dass... |
| Concluding | Wir sind uns also einig, dass... |
| Summarising difference | Wir sehen das unterschiedlich, aber... |

### Register and politeness

In the discussion, use `du` (with a partner your age) or `Sie` (with an examiner/older partner) consistently. Soften disagreement with the Konjunktiv II.

| Blunt | Polite |
|---|---|
| Das ist falsch. | Das sehe ich etwas anders. |
| Nein. | Da bin ich mir nicht so sicher. |
| Du hast Unrecht. | Ich habe da eine andere Sicht. |

### Managing the presentation

| Issue | Solution |
|---|---|
| Forgetting a word | Umschreiben: "Ich meine so etwas wie..." |
| Losing the thread | "Wie gesagt..." / "Um auf ... zurückzukommen" |
| Running out of time | "Ich komme zum Schluss." |
| Too much time left | Add an example or a personal note |

### Useful connective phrases for speech

| German | English |
|---|---|
| zunächst einmal | first of all |
| darüber hinaus | moreover |
| im Gegensatz dazu | in contrast |
| was ... betrifft | as far as ... is concerned |
| einerseits ... andererseits | on the one hand ... on the other |
| letztendlich | ultimately |
| aus diesem Grund | for this reason |

### Practice plan

1. **Record yourself** giving a 4-minute presentation; listen back.
2. **Use a fixed structure** every time until it is automatic.
3. **Learn 5 phrases per function** and rotate them.
4. **Practise with a partner** on iTalki, focusing on the discussion part.
5. **Time yourself** so you know what 4 minutes feels like.

### Practical B2 rules

1. **Always structure** a presentation: intro, outline, points, conclusion.
2. **Use signposting phrases** so the listener can follow.
3. **Soften disagreement** with the Konjunktiv II.
4. **Use `du` or `Sie` consistently** in the discussion.
5. **Practise aloud**; reading silently does not build speaking fluency.

## Exercises

**1. Which function?** (opening, main part, closing, question)

a) Mein Thema heute ist... → ______
b) Ein Beispiel dafür ist... → ______
c) Zusammenfassend lässt sich sagen, dass... → ______
d) Haben Sie Fragen? → ______

**2. Complete the presentation opening.**

Mein Thema heute ______ Online-Lernen. Ich ______ mich dafür entschieden, ______ ich selbst online lerne. Zuerst ______ ich die Vorteile, dann die Nachteile.

**3. Make the disagreement polite.**

a) Das ist falsch. → ______
b) Nein. → ______
c) Du hast Unrecht. → ______

**4. Discussion phrases.**

a) Agreeing → ______
b) Partly agreeing → ______
c) Asking for the partner's view → ______
d) Interrupting politely → ______

**5. Structure a presentation.** Put in order.

a) Schluss
b) Einleitung
c) Gliederung
d) Hauptteil

**6. Translate into German.**

a) My topic today is online learning.
b) First I will explain the advantages.
c) One example of that is...
d) I am of the opinion that...
e) I see it somewhat differently.
f) Thank you for your attention. Do you have questions?

**7. Fix the mistake.**

a) A presentation with no structure.
b) Blunt disagreement: `Das ist falsch.`
c) Mixing du and Sie in one discussion.
d) No signposting phrases; the listener cannot follow.

## Pronunciation note

Presentation German is slower and clearer. Practise pausing at signposting phrases: `Zuerst ... (pause) ... möchte ich ... nennen.` The pauses make you sound organised.

## Common mistakes

- Wrong: presenting without a clear structure.
- Wrong: blunt disagreement, which sounds aggressive.
- Wrong: no signposting, so the listener loses the thread.
- Wrong: mixing du and Sie.
- Wrong: not practising aloud.
