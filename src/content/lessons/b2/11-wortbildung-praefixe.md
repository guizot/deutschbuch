# Lektion 11: Wortbildung — Präfixe

**Level:** B2 | **Target time:** 30 minutes, repeat over 4 sessions | **Status:** not started

---

## Goal

Use German prefixes to multiply your vocabulary, and understand the meaning each prefix adds.

## Why this matters

German builds words with prefixes, and the same prefix adds a similar meaning each time. Learn ten prefixes and you unlock hundreds of words you have never memorised. This is the highest-return vocabulary lesson at B2: it turns passive recognition into active production.

---

## Material

### Why prefixes matter

`sprechen` → `besprechen`, `entsprechen`, `versprechen`, `aussprechen`, `zusprechen`, `ansprechen`, `absprechen`.

Seven words from one root. Each prefix adds meaning. Learn the prefix patterns, and you can decode new words.

### The inseparable prefixes (unstressed)

These prefixes stay attached and are never stressed.

| Prefix | Meaning | Example |
|---|---|---|
| be- | makes a verb transitive / intensifies | arbeiten → bearbeiten |
| ent- | away, removal, beginning | kommen → entkommen |
| er- | result, achievement | lernen → erlernen |
| ge- | (past participle / collective) | hören → gehört |
| ver- | change, wrong, away | kaufen → verkaufen |
| zer- | into pieces | brechen → zerbrechen |
| emp- | (variant of ent-) | finden → empfinden |
| miss- | wrong, bad | verstehen → missverstehen |

### The separable prefixes (stressed)

These prefixes separate in the present and go to the end of the clause.

| Prefix | Meaning | Example |
|---|---|---|
| ab- | away, down, off | fahren → abfahren |
| an- | on, towards, beginning | kommen → ankommen |
| auf- | up, open, completion | stehen → aufstehen |
| aus- | out, exit, completion | gehen → ausgehen |
| bei- | along, contribute | tragen → beitragen |
| ein- | in, into | steigen → einsteigen |
| mit- | along, together | kommen → mitkommen |
| nach- | after, follow | machen → nachmachen |
| vor- | before, forward, demonstrate | stellen → vorstellen |
| weg- | away | gehen → weggehen |
| weiter- | onward, continue | machen → weitermachen |
| zurück- | back | kommen → zurückkommen |
| zusammen- | together | arbeiten → zusammenarbeiten |

### be- : transitive / intensive

`be-` often makes an intransitive verb transitive or intensifies it.

| Base | With be- | Meaning |
|---|---|---|
| arbeiten | bearbeiten | to process, edit |
| antworten | beantworten | to answer (a question) |
| kommen | bekommen | to receive |
| sprechen | besprechen | to discuss |
| suchen | besuchen | to visit |
| fragen | befragen | to question |
| achten | beachten | to observe, heed |

`Ich **beantworte** die Frage.` (I answer the question — transitive.)

### ver- : change, wrong, away

`ver-` is the most productive prefix and the most varied.

| Base | With ver- | Meaning |
|---|---|---|
| kaufen | verkaufen | to sell |
| stehen | verstehen | to understand |
| ändern | verändern | to change |
| brauchen | verbrauchen | to consume |
| suchen | versuchen | to try |
| sprechen | versprechen | to promise |
| lassen | verlassen | to leave |
| meiden | vermeiden | to avoid |
| bieten | verbieten | to forbid |

**Common meanings of ver-:** away from (verkaufen), change (verändern), wrong (sich verhören), use up (verbrauchen).

| Prefix | Meaning | Examples |
|---|---|---|
| ab- | away, off, down | abfahren, abnehmen, abholen |
| an- | on, towards, begin | ankommen, anrufen, anfangen |
| auf- | up, open, complete | aufstehen, aufmachen, aufhören |

| zusammen- | together | zusammenarbeiten, zusammenfassen |

### Recognising the pattern

When you meet a new prefixed verb, ask:

1. **What is the base?** (kaufen → kaufen)
2. **What does the prefix add?** (ver- → away / change)
3. **What does the whole word mean?** (verkaufen → sell)

`verbrauchen` = ver- (use up) + brauchen (need) → to consume.

### Noun prefixes

| Prefix | Meaning | Example |
|---|---|---|
| un- | not, opposite | das Glück → das Unglück |
| miss- | bad, wrong | der Erfolg → der Misserfolg |
| ge- | collective | der Berg → das Gebirge |
| ur- | original, ancient | der Wald → der Urwald |
| haupt- | main | die Stadt → die Hauptstadt |
| neben- | secondary | die Rolle → die Nebenrolle |

### Adjective prefixes

| Prefix | Meaning | Example |
|---|---|---|
| un- | not | möglich → unmöglich |
| in- | not (Latin) | korrekt → inkorrekt |
| super- | very | gut → supergut |
| über- | over, too much | müde → übermüdet |
| unter- | under, too little | ernährt → unterernährt |
| alt- | old | bekannt → altbekannt |

### Practical B2 rules

1. **Learn the prefix meanings**, not each word separately.
2. **Inseparable prefixes** (be-, ent-, er-, ge-, ver-, zer-, miss-) are unstressed and never separate.
3. **Separable prefixes** (ab-, an-, auf-, aus-, ein-, mit-, vor-, zu-) are stressed and separate.
4. **Use prefixes to guess** the meaning of new words while reading.
5. **Watch the accent** to know which type a prefix is.

## Pronunciation note

Separable prefixes are **stressed**: `AUFstehen`, `ANkommen`, `MITkommen`. Inseparable prefixes are **unstressed**: `verSTEHEN`, `beKOMMEN`, `entDECKEN`. The stress tells you the type.

## Common mistakes

- Wrong: separating an inseparable prefix: `Ich stehe ver...`. Right: `verstehen` stays whole.
- Wrong: not separating a separable prefix: `Ich aufstehe`. Right: `Ich stehe auf`.
- Wrong: stressing an inseparable prefix. Right: `verSTEHEN`.
- Wrong: assuming the prefix always means the same. `ver-` has several meanings.
- Wrong: guessing a meaning without checking. Verify with a dictionary the first time.
