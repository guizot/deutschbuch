# Lektion 12: Wortbildung — Suffixe und Komposita

**Level:** B2 | **Target time:** 30 minutes, repeat over 4 sessions | **Status:** not started

---

## Goal

Use suffixes to build nouns, adjectives, and verbs, and decode German compound nouns.

## Why this matters

German loves compounds (`Krankenhaus`, `Handschuh`, `Umweltschutz`) and suffixes (`-ung`, `-heit`, `-keit`). Knowing the patterns lets you understand and create words without memorising each one. Compound gender and meaning rules are tested, and suffixes are a fast route to vocabulary.

## Material

### Noun suffixes: feminine (-ung, -heit, -keit, -schaft)

| Suffix | Gender | Example | Meaning |
|---|---|---|---|
| -ung | f | die Prüfung | action/result of verb |
| -heit | f | die Freiheit | quality |
| -keit | f | die Möglichkeit | quality |
| -schaft | f | die Freundschaft | collective/abstract |
| -ion | f | die Diskussion | action |
| -tät | f | die Realität | quality |
| -enz | f | die Konsequenz | quality |
| -anz | f | die Toleranz | quality |

`**-ung**` is the most productive: `prüfen → die Prüfung`, `entwickeln → die Entwicklung`.

### Noun suffixes: masculine (-er, -ling, -ismus)

| Suffix | Gender | Example | Meaning |
|---|---|---|---|
| -er | m | der Lehrer | person who does |
| -ler | m | der Sportler | person associated |
| -ner | m | der Rentner | person associated |
| -ling | m | der Lehrling | person (often young) |
| -ismus | m | der Kapitalismus | system |
| -ant | m | der Demonstrant | person (weak noun) |
| -ent | m | der Student | person (weak noun) |
| -ist | m | der Journalist | person (weak noun) |

### Noun suffixes: neuter (-chen, -lein, -tum, -nis)

| Suffix | Gender | Example | Meaning |
|---|---|---|---|
| -chen | n | das Mädchen | diminutive |
| -lein | n | das Fräulein | diminutive |
| -tum | n | das Wachstum | state/collective |
| -nis | n | das Ergebnis | result |
| -ment | n | das Dokument | object |
| -um | n | das Studium | abstract |

**Note:** diminutives `-chen` and `-lein` are **always neuter**, even when the base is masculine or feminine.

`die Frau → das Fräulein`, `der Mann → das Männchen`.

### Adjective suffixes

| Suffix | Meaning | Example |
|---|---|---|
| -lich | characteristic of | freundlich, möglich |
| -ig | having | hungrig, sonnig |
| -isch | relating to | typisch, kindisch |
| -bar | possible | machbar, lösbar |
| -sam | inclined to | sparsam, gemeinsam |
| -haft | having the quality | lebhaft, mangelhaft |
| -los | without | arbeitslos, sinnlos |
| -voll | full of | sinnvoll, kraftvoll |
| -arm | poor in | wasserarm |
| -reich | rich in | wasserreich |

### Verb suffixes

| Suffix | Meaning | Example |
|---|---|---|
| -ieren | (from Latin/French) | studieren, telefonieren |
| -eln | frequentative | lächeln, klingeln |
| -ern | frequentative | blinkern, wandern |
| -igen | make (from adjective) | reinigen, festigen |

**Note:** verbs in `-ieren` have **no ge-** in the Partizip II.

`studieren → studiert`, `telefonieren → telefoniert`.

### Compound nouns (Komposita)

German combines words freely: `Krankenhaus` = `Kranke` + `Haus`.

**Gender rule:** the compound takes the gender of the **last** element.

`das Haus` → `das Krankenhaus`
`die Tür` → `die Haustür`
`der Schuh` → `der Handschuh`

**This rule is tested constantly.** Always look at the last word.

### The linking element (-s-, -n-, -en-)

Sometimes a linking sound appears between the parts.

| Link | Example | Meaning |
|---|---|---|
| -s- | die Arbeitszeit | work + time |
| -n- | der Sonnenschein | sun + shine |
| -en- | der Studentenausweis | student + ID |
| -er- | der Wörterbuch | word + book |

`die Arbeit + die Zeit = die Arbeitszeit`
`der Student + der Ausweis = der Studentenausweis`

### Decoding compounds

Read from the last element backwards, and the last element gives the category.

`der Handschuh` = Hand + Schuh = a shoe for the hand = glove
`der Kühlschrank` = kühl + Schrank = a cool cupboard = fridge
`das Krankenhaus` = Kranke + Haus = a house for the sick = hospital
`die Umweltschutz` = Umwelt + Schutz = environment + protection
`der Fernseher` = fern + Seher = far + seer = television

### Compound types

| Type | Example | Meaning |
|---|---|---|
| Noun + noun | Haustür | front door |
| Verb + noun | Waschmaschine | washing machine |
| Adjective + noun | Großstadt | big city |
| Preposition + noun | Vorort | suburb |
| Noun + adjective | wasserreich | rich in water |

### Long compounds

German can chain three or four elements.

`die Krankenversicherung` = Kranke + Versicherung = health insurance
`das Umweltschutzgesetz` = Umwelt + Schutz + Gesetz = environmental protection law
`die Straßenbahnhaltestelle` = Straße + Bahn + Haltestelle = tram stop

**Reading strategy:** split at each meaningful boundary, then read the last element first.

### Compound with an article: gender check

| Compound | Last element | Gender |
|---|---|---|
| das Krankenhaus | Haus (n) | n |
| die Haustür | Tür (f) | f |
| der Handschuh | Schuh (m) | m |
| das Arbeitszimmer | Zimmer (n) | n |
| die Großstadt | Stadt (f) | f |

### Practical B2 rules

1. **Compound gender = the last element's gender.**
2. **-ung, -heit, -keit, -schaft are feminine.**
3. **-er, -ling, -ismus are masculine.**
4. **-chen, -lein, -tum, -nis are neuter.**
5. **-ieren verbs have no ge- in the Partizip II.**
6. **Decode compounds from the last element backwards.**

## Pronunciation note

In compounds, the **first element is stressed**: `HANDschuh`, `KRANKenhaus`, `UMweltschutz`. The suffix is usually unstressed: `PRÜfung`, `FREIheit`.

## Common mistakes

- Wrong: giving a compound the gender of the first element. Right: the last element decides.
- Wrong: `der Großstadt`. Right: `die Großstadt` (Stadt is feminine).
- Wrong: adding ge- to -ieren verbs: `gestudiert`. Right: `studiert`.
- Wrong: misreading long compounds. Split them at meaningful boundaries.
- Wrong: ignoring the linking element: `Arbeitzeit`. Right: `Arbeitszeit`.
