# Lektion 02: Passiv-Ersatzformen

**Level:** B2 | **Target time:** 30 minutes, repeat over 3 sessions | **Status:** not started

---

## Goal

Replace the passive with the five main alternatives, and choose the right one for the register.

## Why this matters

Good German does not use the passive in every sentence. There are five ways to express "it is done" without the passive, and a B2 writer varies them. Exam markers reward this, and the alternatives are individually tested (especially `sich lassen` and `sein + zu`).

---

## Material

### The five alternatives

| Structure | Example | Meaning |
|---|---|---|
| **man** | Man baut das Haus. | One builds the house. |
| **sich lassen** | Das Haus lässt sich bauen. | The house can be built. |
| **sein + zu + Inf.** | Das Haus ist zu bauen. | The house is to be built. |
| **-bar adjective** | Das Haus ist baubar. | The house is buildable. |
| **bleiben / gehen / stehen** | Das Haus bleibt geschlossen. | The house stays closed. |

### Alternative 1: man

The most common informal replacement. `man` = "one", "people", "you" in general.

| Passive | man |
|---|---|
| Das Formular wird ausgefüllt. | Man füllt das Formular aus. |
| Hier wird nicht geraucht. | Hier raucht man nicht. |
| Die Rechnung wird bezahlt. | Man bezahlt die Rechnung. |

**Register:** neutral to informal. Very common in speech and instruction.

### Alternative 2: sich lassen

`sich lassen + Infinitiv` = "can be done". Replaces `können` + passive.

| Passive | sich lassen |
|---|---|
| Das Problem kann gelöst werden. | Das Problem lässt sich lösen. |
| Das kann gemacht werden. | Das lässt sich machen. |
| Das kann nicht geändert werden. | Das lässt sich nicht ändern. |

**Conjugation of lassen:** ich lasse, du lässt, er lässt, wir lassen, ihr lasst, sie lassen.
**Präteritum:** ich ließ, du ließest, er ließ, wir ließen, ihr ließt, sie ließen.

`Das **ließ sich** nicht vermeiden.` (That could not be avoided.)

**Register:** neutral, elegant, common in both speech and writing.

### Alternative 3: sein + zu + Infinitiv

`sein + zu + Infinitiv` = "is to be done" (obligation) or "can be done" (possibility).

| Passive | sein + zu |
|---|---|
| Das Formular muss ausgefüllt werden. | Das Formular ist auszufüllen. |
| Die Rechnung muss bis Freitag bezahlt werden. | Die Rechnung ist bis Freitag zu bezahlen. |
| Das Problem kann gelöst werden. | Das Problem ist zu lösen. |

**Register:** formal, common in written German (rules, contracts, manuals).

**Note:** the infinitive is written as one word with `zu`: `auszufüllen`, `zu bezahlen`.

### Alternative 4: -bar adjectives

Many verbs form an adjective with **-bar** meaning "can be done".

| Verb | Adjective | Meaning |
|---|---|---|
| machen | machbar | doable |
| lösen | lösbar | solvable |
| bezahlen | bezahlbar | payable, affordable |
| essen | essbar | edible |
| trinken | trinkbar | drinkable |
| reparieren | reparierbar | repairable |
| ändern | veränderbar | changeable |
| erreichen | erreichbar | reachable |
| vergleichen | vergleichbar | comparable |
| nachweisen | nachweisbar | provable |
| messen | messbar | measurable |
| lesen | lesbar | readable |
| verstehen | verständlich* | understandable |

`Das ist **machbar**.` (That is doable.)
`Das Ziel ist **erreichbar**.` (The goal is reachable.)

**Register:** neutral, descriptive. Describes a quality of the thing.

### Alternative 5: bleiben, gehen, stehen + Partizip II

Some verbs combine with a participle to replace the passive.

| Structure | Example | Meaning |
|---|---|---|
| bleiben + P2 | Das Fenster bleibt geschlossen. | The window stays closed. |
| gehen + P2 | Das geht nicht mehr. | That no longer works. |
| stehen + P2 | Das steht noch offen. | That is still open. |
| kommen + P2 | Das kommt nicht in Frage. | That is out of the question. |

`Die Tür **bleibt** geschlossen.` (The door stays closed.)
`Das **ist** noch **zu** klären.` (That is still to be clarified.)

### Choosing the right alternative

| Register | Best choice |
|---|---|
| Casual speech | man |
| Neutral, elegant | sich lassen |
| Formal, written obligation | sein + zu + Infinitiv |
| Describing a quality | -bar adjective |
| State that continues | bleiben + P2 |

### Worked comparison: same idea, five ways

1. **Passive:** Das Problem kann gelöst werden.
2. **man:** Man kann das Problem lösen.
3. **sich lassen:** Das Problem lässt sich lösen.
4. **sein + zu:** Das Problem ist zu lösen.
5. **-bar:** Das Problem ist lösbar.

All five are correct. Varying them is a mark of good style.

### Negation with the alternatives

| Structure | Negative |
|---|---|
| sich lassen | Das lässt sich nicht ändern. |
| sein + zu | Das ist nicht zu ändern. |
| -bar | Das ist nicht machbar. / Das ist unmachbar. |
| man | Man kann das nicht ändern. |

### The "-lich" adjectives (related but not passive)

Some verbs form adjectives with **-lich** instead of **-bar**. These describe a tendency, not a possibility.

| Verb | Adjective |
|---|---|
| verstehen | verständlich (understandable) |
| glauben | glaublich / unglaublich |
| bezahlen | bezahllich (rare) |
| vermeiden | vermeidlich (rare) |

`verständlich` and `unglaublich` are common; the others are rare.

## Pronunciation note

`sich lassen` — the stress is on `LASsen`. `auszufüllen` is stressed on the first syllable of the verb stem: "OWS-tsu-fül-len". `veränderbar` is stressed on "ÄN".

## Common mistakes

- Wrong: `Das lässt sich lösen werden`. Right: `Das lässt sich lösen`.
- Wrong: `Das Formular ist ausfüllen`. Right: `ist auszufüllen`.
- Wrong: using `man` in a formal contract. Right: `sein + zu`.
- Wrong: confusing `-bar` (possible) with `-lich` (a tendency).
- Wrong: forgetting that `sich lassen` takes a bare infinitive.
