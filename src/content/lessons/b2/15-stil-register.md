# Lektion 15: Stil — Formelles und informelles Register

**Level:** B2 | **Target time:** 30 minutes, repeat over 2 sessions | **Status:** not started

---

## Goal

Choose the right register for each situation, and convert between formal and informal German.

## Why this matters

At B2, being understood is not enough; you must sound appropriate. Writing to a landlord in the wrong register, or a friend in officialese, both fail. Exams test this directly, and professional life depends on it. Register is the difference between competent and truly proficient.

---

## Material

### What register means

Register = the level of formality, shaped by:

- **Vocabulary** (simple vs elevated)
- **Grammar** (verbal vs nominal, active vs passive)
- **Address** (du vs Sie)
- **Contractions and particles**
- **Sentence length and complexity**

### The two poles

| Informal | Formal |
|---|---|
| du | Sie |
| Hallo | Sehr geehrte... |
| simple verbs | Funktionsverbgefüge |
| verbal style | nominal style |
| short sentences | longer, complex |
| modal particles | no particles |
| contractions | full forms |

### Vocabulary: informal vs formal

| Informal | Formal | Meaning |
|---|---|---|
| kriegen | erhalten, bekommen | to get |
| machen | durchführen, vornehmen | to do |
| sagen | mitteilen, äußern | to say |
| fragen | anfragen, sich erkundigen | to ask |
| helfen | unterstützen, Hilfe leisten | to help |
| zeigen | darlegen, aufzeigen | to show |
| gut | positiv, zufriedenstellend | good |
| schlecht | negativ, unzureichend | bad |
| echt | tatsächlich, tatsächlich | really |
| vielleicht | möglicherweise, eventuell | maybe |
| aber | jedoch, allerdings | but |
| also | folglich, demnach | so |

### Grammar: verbal vs nominal

| Informal (verbal) | Formal (nominal) |
|---|---|
| Weil es regnete, ... | Wegen des Regens, ... |
| Man muss prüfen. | Eine Prüfung ist erforderlich. |
| Er hat entschieden. | Die Entscheidung wurde getroffen. |
| Ich finde das gut. | Das erachte ich als positiv. |

### Passive and Funktionsverbgefüge in formal register

Formal German prefers:
- **Passive** over active: `Es wurde beschlossen` vs `Man beschloss`
- **Funktionsverbgefüge**: `eine Entscheidung treffen` vs `entscheiden`
- **Nominalisation**: `die Durchführung` vs `durchführen`
- **Konjunktiv II** for politeness: `Ich würde bitten` vs `Ich bitte`

### Address: du vs Sie

| Informal | Formal |
|---|---|
| Wie geht's dir? | Wie geht es Ihnen? |
| Kannst du...? | Könnten Sie...? |
| Dein Brief | Ihr Schreiben |
| Ich schreibe dir. | Ich schreibe Ihnen. |

**Never mix them.** Choose one and stay consistent.

### Contractions and particles

| Informal | Formal |
|---|---|
| Ich hab' | Ich habe |
| Wie geht's? | Wie geht es Ihnen? |
| Komm mal her. | Kommen Sie bitte her. |
| Das ist ja toll! | Das ist sehr erfreulich. |
| Na ja, also... | — (particles are dropped) |

Modal particles (doch, mal, ja, denn) belong to informal speech; formal writing omits them.

### Sentence structure

| Informal | Formal |
|---|---|
| Kurze Sätze. | Längere, komplexe Sätze. |
| Aber das ist falsch. | Dies ist jedoch nicht zutreffend. |
| Und dann... | Darüber hinaus... |

### Converting: informal to formal

| Informal | Formal |
|---|---|
| Hallo, ich hab' ein Problem mit meiner Bestellung. | Sehr geehrte Damen und Herren, ich wende mich an Sie bezüglich meiner Bestellung. |
| Kannst du mir helfen? | Könnten Sie mir bitte behilflich sein? |
| Das ist echt blöd. | Dies ist leider sehr ungünstig. |
| Ich will das zurück. | Ich bitte um eine Rückerstattung. |
| Schreib mir bald. | Ich würde mich über eine baldige Rückmeldung freuen. |

### Converting: formal to informal

| Formal | Informal |
|---|---|
| Ich wende mich an Sie bezüglich... | Ich schreib dir wegen... |
| Ich bitte um Rückmeldung. | Sag mir bitte Bescheid. |
| Dies ist leider ungünstig. | Das ist echt blöd. |
| Ich würde mich freuen. | Ich freu mich. |

### Register by text type

| Text type | Register |
|---|---|
| Email to a friend | informal |
| Email to a company | formal |
| Job application | formal |
| Forum post | neutral to informal |
| Complaint letter | formal |
| Report | formal |
| Social media | informal |
| Academic text | formal |

### Practical B2 rules

1. **Identify the audience first**, then choose the register.
2. **Formal:** Sie, no particles, passive/nominal, Funktionsverbgefüge, full forms.
3. **Informal:** du, particles, active/verbal, contractions.
4. **Never mix** registers in one text.
5. **Formal writing** prefers the Konjunktiv II for requests.

## Exercises

**1. Informal or formal?**

a) Wie geht's dir? → ______
b) Wie geht es Ihnen? → ______
c) Kannst du mir helfen? → ______
d) Könnten Sie mir behilflich sein? → ______

**2. Replace with the formal equivalent.**

a) kriegen → ______
b) machen → ______
c) sagen → ______
d) aber → ______
e) vielleicht → ______

**3. Replace with the informal equivalent.**

a) erhalten → ______
b) mitteilen → ______
c) jedoch → ______
d) möglicherweise → ______

**4. Convert to formal.**

a) Hallo, ich hab' ein Problem mit meiner Bestellung. → ______
b) Kannst du mir helfen? → ______
c) Das ist echt blöd. → ______
d) Schreib mir bald. → ______

**5. Convert to informal.**

a) Ich wende mich an Sie bezüglich... → ______
b) Ich bitte um Rückmeldung. → ______
c) Dies ist leider ungünstig. → ______

**6. Choose the right register for the text type.**

a) Email to a friend → ______
b) Job application → ______
c) Forum post → ______
d) Complaint letter → ______

**7. Fix the mistake (mixed register).**

a) Sehr geehrter Herr Müller, kannst du mir helfen?
b) Hallo Anna, ich würde mich über eine Rückmeldung freuen.
c) Sehr geehrte Damen und Herren, das ist ja echt blöd.

### Answer key

**1.**
a) informal
b) formal
c) informal
d) formal

**2.**
a) erhalten
b) durchführen / vornehmen
c) mitteilen
d) jedoch
e) möglicherweise

**3.**
a) kriegen / bekommen
b) sagen
c) aber
d) vielleicht

**4.**
a) Sehr geehrte Damen und Herren, ich wende mich an Sie bezüglich meiner Bestellung.
b) Könnten Sie mir bitte behilflich sein?
c) Dies ist leider sehr ungünstig.
d) Ich würde mich über eine baldige Rückmeldung freuen.

**5.**
a) Ich schreib dir wegen...
b) Sag mir bitte Bescheid.
c) Das ist echt blöd.

**6.**
a) informal
b) formal
c) neutral to informal
d) formal

**7.**
a) Mixed: `Sehr geehrter Herr Müller` (formal) + `kannst du` (informal). Use either `Könnten Sie mir helfen?` (formal) or `Hallo Herr Müller, kannst du mir helfen?` (informal address).
b) Mixed: `Hallo Anna` (informal) + `ich würde mich über eine Rückmeldung freuen` (formal). Use `Ich freu mich, wenn du mir schreibst.`
c) Mixed: formal salutation + informal particle. Use `Das ist leider sehr ungünstig.`

## Pronunciation note

Formal German is spoken slightly more slowly and with fuller forms. Informal German contracts and speeds up: `hab'`, `geht's`, `is'`. Listen for these in Easy German.

## Common mistakes

- Wrong: mixing du and Sie in one text.
- Wrong: using modal particles in formal writing (`ja`, `doch`, `mal`).
- Wrong: using simple verbs in a formal letter (`kriegen` instead of `erhalten`).
- Wrong: over-formalising a message to a friend; it sounds cold.
- Wrong: contractions in formal writing (`hab'` instead of `habe`).
