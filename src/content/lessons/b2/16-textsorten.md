# Lektion 16: Textsorten — Bericht, Aufsatz, Leserbrief

**Level:** B2 | **Target time:** 30 minutes, repeat over 3 sessions | **Status:** not started

---

## Goal

Write the main B2 text types: report, argumentative essay, reader's letter, forum post, and formal letter — each with its own structure and register.

## Why this matters

The B2 writing exam requires you to produce specific text types. Each has conventions: a report is factual, an essay argues, a reader's letter responds. Knowing the structure means you spend your exam time on language, not layout. This is the most directly exam-relevant lesson.

---

## Material

### Overview of B2 text types

| Text type | Purpose | Register |
|---|---|---|
| Bericht (report) | report facts | formal, factual |
| Aufsatz (essay) | argue a position | formal |
| Leserbrief (reader's letter) | respond to an article | formal to neutral |
| Forumsbeitrag (forum post) | express and discuss opinion | neutral |
| Formeller Brief | request, complaint, application | formal |
| E-Mail (informal) | personal communication | informal |

### 1. Der Bericht (report)

**Purpose:** report what happened, factually and objectively.

**Structure:**
1. **Einleitung:** what, when, where, who
2. **Hauptteil:** the events, in order
3. **Schluss:** result, consequence

**Language:** Präteritum, passive, nominal style, no opinion.

```
**Betreff:** Bericht über das Sommerfest 2026

**Einleitung:** Am 15. Juli 2026 fand das jährliche Sommerfest
der Firma statt.

**Hauptteil:** Um 14 Uhr wurde das Fest eröffnet. Anschließend
wurden verschiedene Aktivitäten durchgeführt. Gegen 17 Uhr
trat die Band auf.

**Schluss:** Insgesamt nahmen etwa 200 Personen teil. Das Fest
verlief erfolgreich.
```

**Key phrases:** `fand statt`, `wurde durchgeführt`, `verlief`, `insgesamt`.

### 2. Der Aufsatz (argumentative essay)

**Purpose:** argue a position on a topic.

**Structure:**
1. **Einleitung:** introduce the topic, state your position
2. **Argument 1:** reason + example
3. **Argument 2:** reason + example
4. **Gegenargument:** acknowledge the other side, refute it
5. **Schluss:** restate position, conclusion

**Language:** present tense, connectors (deshalb, außerdem, trotzdem), Konjunktiv II for hedging.

```
**Einleitung:** Immer mehr Menschen lernen online. Meiner Meinung
nach hat das sowohl Vorteile als auch Nachteile.

**Argument 1:** Ein Vorteil ist, dass man flexibel lernen kann.
Zum Beispiel kann man jederzeit und überall studieren.

**Argument 2:** Außerdem sind Online-Kurse oft günstiger.

**Gegenargument:** Natürlich fehlt der persönliche Kontakt.
Trotzdem überwiegen meiner Ansicht nach die Vorteile.

**Schluss:** Aus diesen Gründen halte ich Online-Lernen für sinnvoll.
```

### 3. Der Leserbrief (reader's letter)

**Purpose:** respond to a published article.

**Structure:**
1. **Bezug:** refer to the article
2. **Position:** agree or disagree
3. **Arguments:** with reasons
4. **Schluss:** final opinion, polite closing

**Key phrases:**
`Mit Interesse habe ich Ihren Artikel ... gelesen.`
`Ich stimme dem Autor zu, dass...`
`Allerdings sehe ich das anders, weil...`
`Abschließend möchte ich betonen, dass...`

### 4. Der Forumsbeitrag (forum post)

**Purpose:** express an opinion in an online discussion.

**Structure:** similar to the essay, but more informal.

**Key phrases:**
`Ich möchte auch etwas dazu sagen.`
`Meiner Erfahrung nach...`
`Ich sehe das ähnlich wie...`
`Was mich betrifft, ...`

### 5. Der formelle Brief (formal letter)

**Structure:**
1. **Betreff**
2. **Anrede** (Sehr geehrte...)
3. **Einleitung** (reason)
4. **Hauptteil** (details)
5. **Schluss** (request)
6. **Grußformel** (Mit freundlichen Grüßen)

**Key phrases:** see Lektion 21 of B1.

### 6. Die informelle E-Mail

**Structure:** greeting, message, closing.

**Key phrases:**
`Hallo ..., wie geht's?`
`Ich wollte dir erzählen, dass...`
`Schreib mir bald!`
`Liebe Grüße`

### Text type by task wording

| Task says... | Write... |
|---|---|
| "Berichten Sie" | Bericht |
| "Nehmen Sie Stellung" | Aufsatz / Forumsbeitrag |
| "Schreiben Sie einen Leserbrief" | Leserbrief |
| "Schreiben Sie eine E-Mail an..." | depends on recipient |
| "Beschweren Sie sich" | formal complaint |
| "Bewerben Sie sich" | application |

### Common structure phrases

| Function | Phrase |
|---|---|
| Opening (report) | Am ... fand ... statt. |
| Opening (essay) | In der heutigen Zeit ist ... ein wichtiges Thema. |
| Opening (reader's letter) | Mit Interesse habe ich Ihren Artikel gelesen. |
| Adding | Außerdem, darüber hinaus, zudem |
| Contrasting | Allerdings, jedoch, im Gegensatz dazu |
| Conceding | Natürlich, es stimmt, dass... |
| Concluding | Abschließend, zusammenfassend, aus diesen Gründen |
| Closing (formal) | Mit freundlichen Grüßen |
| Closing (informal) | Liebe Grüße |

### Planning your text (5 minutes in the exam)

1. **Read the task** carefully: what text type, what register, what content points?
2. **Plan the structure:** Einleitung, 2-3 arguments, Schluss.
3. **Note the key vocabulary** you will need.
4. **Write.**
5. **Check:** verb positions, cases, register consistency.

### Cohesion devices

| Device | Example |
|---|---|
| Pronouns | Er, sie, es |
| Reference words | dieser, jener, solcher |
| Connectors | deshalb, außerdem, trotzdem |
| Repetition with variation | das Problem → diese Schwierigkeit |
| Time markers | zuerst, danach, schließlich |

### Practical B2 rules

1. **Identify the text type** from the task wording.
2. **Use the right register** for the type.
3. **Plan before writing** (5 minutes).
4. **Use connectors** to link paragraphs.
5. **Check register consistency** at the end.

**3. Match the phrase to the text type.**

a) Mit Interesse habe ich Ihren Artikel gelesen. → ______
b) Am 15. Juli fand das Fest statt. → ______
c) Meiner Meinung nach... → ______
d) Mit freundlichen Grüßen → ______

**4. Structure an essay.** Put the parts in order.

a) Schluss
b) Einleitung
c) Gegenargument
d) Argument 1

**5. Complete the report.**

Am 15. Juli ______ (stattfinden) das Sommerfest. Um 14 Uhr ______ (eröffnen, Passiv) das Fest. Insgesamt ______ (teilnehmen) etwa 200 Personen.

**6. Translate into German (text phrases).**

a) In my opinion, there are both advantages and disadvantages.
b) One advantage is that one can learn flexibly.
c) Of course, personal contact is missing.
d) Nevertheless, the advantages outweigh.
e) For these reasons I consider it sensible.

**7. Fix the mistake.**

a) An essay with `Hallo` and `Liebe Grüße`.
b) A report with strong opinions (`Ich finde das toll`).
c) A reader's letter without a reference to the article.
d) Mixing `du` and `Sie` in a formal letter.

### Answer key

**1.**
a) Bericht
b) Aufsatz / Forumsbeitrag
c) Leserbrief
d) formeller Brief

**2.**
a) formal, factual
b) informal
c) formal to neutral
d) neutral

**3.**
a) Leserbrief
b) Bericht
c) Aufsatz / Forumsbeitrag
d) formeller Brief

**4.**
b) Einleitung
d) Argument 1
e) Argument 2
c) Gegenargument
a) Schluss

**5.**
Am 15. Juli **fand** das Sommerfest **statt**. Um 14 Uhr **wurde** das Fest **eröffnet**. Insgesamt **nahmen** etwa 200 Personen **teil**.

**6.**
a) Meiner Meinung nach gibt es sowohl Vorteile als auch Nachteile.
b) Ein Vorteil ist, dass man flexibel lernen kann.
c) Natürlich fehlt der persönliche Kontakt.
d) Trotzdem überwiegen die Vorteile.
e) Aus diesen Gründen halte ich es für sinnvoll.

**7.**
a) An essay should use a formal or neutral opening (`In der heutigen Zeit...`), not `Hallo`.
b) A report is factual; opinions belong in an essay.
c) A reader's letter should begin with a reference: `Mit Interesse habe ich Ihren Artikel gelesen.`
d) Choose one address form and stay consistent.

## Pronunciation note

Text-type vocabulary: `Bericht` (be-RIKHT), `Aufsatz` (OWF-zats), `Leserbrief` (LAY-zer-breef), `Stellungnahme` (SHTE-lung-nah-me).

## Common mistakes

- Wrong: using the wrong register for the text type.
- Wrong: writing a report full of opinions.
- Wrong: writing an essay without a clear structure.
- Wrong: omitting the reference in a reader's letter.
- Wrong: no planning; the text loses coherence.
